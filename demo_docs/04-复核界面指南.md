# 复核界面指南

```bash
python3 -m autolabel review datasets/demo        # 默认 https://localhost:8765
python3 -m autolabel review datasets/demo --port 9000 --max-upload-mb 4096
```

纯标准库 HTTP/HTTPS 服务 + 原生 Canvas 前端，无构建步骤、不联网。界面是本地单用户工具，别公网暴露。

`certs/` 里有证书就自动走 HTTPS（跑过一次 `autolabel ca` 就有，一台机器一次）。**摄像头只能在「安全网页」里录像**，HTTP 页面点录制必然被浏览器拒；而且现在的浏览器会自动把 `http://` 升级成 `https://`，纯 HTTP 服务反而会显示「浏览器不支持此网站」。要临时退回 HTTP 用 `--no-ssl`，代价是录不了像。

## 页面结构：一套壳 · 六个页面

一个服务六个页面，共用同一个数据集目录，模块切换在顶栏中文标签和 `⋯` 菜单「去别的模块」两处：

| 地址 | 模块 | 干什么 |
| --- | --- | --- |
| `/`（工作台） | 门户 | **“下一步”行动流**（最多三条，带直达按钮）、五格概览（素材池 / 姿态库 / 提示词库 / 检测库 / 等你复核）、三个标注库 + 素材池摘要卡、三条导出链（骨骼 / 提示词框 / 本机权重框）各带 CSV·JSONL 与导出范围 |
| `/pose` | 姿态标注 | 人体骨骼的自动标注与人工复核（`/review` 是改名前的老地址，同一页） |
| `/pool` | 素材池 | **素材自己的家**：上传只进池不入库、按分类与来处整理、逐张看它被哪几个库引用、挑一批加进某个标注模块、删素材（口径见「素材池」一节） |
| `/objects` | 提示词标注 | 用描述提示词让多模态大模型找物品，产出检测框；删错框、补画漏框都在这里 |
| `/detect` | 目标检测标注 | 本机 YOLO 权重按**它自带的类别表**出检测框；先选权重、再勾权重认识的类别，独立上传口 |
| `/models` | 模型管理 | 按关键词搜五种任务的模型（姿态 / 检测 / 分割 / 旋转框 / 分类）、权重文件、多模态大模型配置 |

- 三个标注库写各自的标签目录，互不覆盖：骨骼写 `labels/`，提示词出的框写 `prompt_labels/`，本机权重出的框写 `detect_labels/`。素材与它的分类、来处归素材池（`images/` + `.autolabel/pool.json`），三个库只存引用和标注结果，索引、批次表、撤销快照各一套。
- **素材归池，标注归库**：同一帧只落盘一次，「这张素材还在不在、被谁在用、是谁传进来的」在 `/pool` 一处说得清；「这张标成什么样、复核到哪一步」留在各库自己的索引里，两边不互相覆盖。
- 工作台的统计一律从当前磁盘上的索引现算，不做缓存，跟复核页看到的数一致。
- 页间跳转只有两处入口：**顶栏的中文模块标签**和 `⋯` 菜单里的「去别的模块」，两处都由 `common.js` 按同一张模块表渲染，以后再加库不会出现「某页跳不过去」。快捷键照旧：姿态页 `O` 跳提示词标注、`M` 跳模型管理；提示词页与目标检测标注页的 `O` 在**这两个库之间来回跳**（同一份素材两边都能标），`P` 回姿态页，`M` 跳模型管理。当前所在模块用天蓝描边标出来——以前只是把底色调深一档，白天主题下和页面底色差不到哪儿去，等于没标。

## 快捷键

以下为**姿态标注**页的按键。提示词标注页与目标检测标注页共用另一套按键（两页同一个前端，只差库配置），见下文同名小节。

| 按键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 命令面板：动作、筛选、按文件名跳帧都能搜（也可点顶栏搜索框） |
| `?` | 本页快捷键速查表（姿态页与两个出框页的数字键含义不同，各查各的） |
| `⌘Z` / `Ctrl+Z` | 撤销上一次修改（与 `U` 同一个动作，手顺着按就行；裸 `Z` 仍是适应窗口） |
| 拖动关键点 | 微调位置（bbox 会自动撑住所有可见点） |
| `J` / `K` | 待办清单下一条 / 上一条（编号与画布上的编号一致） |
| `↑` / `↓` | 在左侧焦点队列里上下移动 |
| `V` | 聚焦模式：非选中目标淡成背景，只盯当前这个改 |
| `0` / `1` / `2` | 选中点设为 忽略 / 遮挡 / 可见 |
| `Q` / `E` | 接受 / 驳回当前图，自动翻页并在画布下方弹 5 秒撤销条；撤销条撤销的是**刚才那一帧的这次定论**（状态退回原样并跳回那一帧），不是翻页后那一帧的坐标 |
| `←` / `→`（或 `A` / `D`） | 上一张 / 下一张 |
| `F` | 跳到下一张待确认（带 QC 标记或整体置信度偏低的图） |
| `X` | 删除选中目标 |
| `[` / `]` | 切换选中目标 |
| `Alt+方向键` | 像素级微调（`Shift` 加大步长） |
| 滚轮 / 空格拖 | 缩放 / 平移 |
| `Z` | 适应窗口 |
| `U` | 撤销一次坐标修改；撤销条还开着时按 `U` 撤销的是刚才那次接受 / 驳回 |
| `B` | 打开批次管理 |
| `W` | 打开导入素材弹层 |
| `G` | **批量姿态标注**：库里已有的图直接跑权重，不用再传一遍（见下文同名小节） |
| `O` | 跳到「提示词标注」模块 |
| `M` | 跳到「模型管理」模块（原来是本页弹层，现在是独立页） |
| `⌥S` | **系统设置**（界面外观 + 推理算力，六个页面通用；也可 `⋯` 菜单 → 系统设置、`⌘K` 搜「系统设置」） |
| `⌥T` | 白天 / 夜晚切换（也可在系统设置面板里选，或 `⌘K` 搜「外观」） |
| `⌥=` / `⌥-` | 字号放大 / 缩小（小 · 标准 · 大 · 特大 四档） |
| `Esc` | 关闭当前弹层 / 菜单 / 命令面板 |

改动防抖 600ms 自动写回标签；首次修改前把自动标注原件备份到 `.autolabel/originals/`，另有最近 10 个历史快照（`.autolabel/history/`），`U` 逐级回滚。

## 系统设置：外观 + 推理算力（`⌥S`）

界面偏好和算力选择收在**同一个面板**，六个页面同一个入口——以前白天 / 夜晚和字号摊在 `⋯` 菜单底部，想换个算力还得去命令行，两处各管各的迟早对不上。

左半是界面外观，记在**本机浏览器**（`localStorage` 的 `autolabel.appearance`）：切页、刷新、重启服务都保持，换浏览器或换电脑需要重设一次；点一下就生效，不用保存。

| 项 | 档位 | 说明 |
| --- | --- | --- |
| 主题 | 跟随系统（默认）/ 白天 / 夜晚 | 「跟随系统」跟着 macOS 的浅色深色自动切换，系统改了界面立刻跟着改 |
| 字号 | 小 / 标准（默认）/ 大 / 特大 | 整站缩放（0.92 / 1 / 1.12 / 1.26 倍），画布上的框标签与 HUD 一起缩放 |

右半是推理算力，存**这台机器**的 `~/.autolabel/settings.json`（`AUTOLABEL_SETTINGS` 可换路径），跟机器不跟数据集——换浏览器打开同一个数据集也认这一份。面板底部写着文件在哪。

| 项 | 档位 | 说明 |
| --- | --- | --- |
| 推理设备 | 自动选择（默认）/ NVIDIA 显卡（CUDA）/ Apple 加速（MPS）/ 纯 CPU | 每一行直接写这台机器**实际识别到什么**：可用就带型号（`NVIDIA GeForce RTX 4090`、`Apple Silicon（arm64）`、`arm64 · 10 核`），用不了就写明原因（`这个 PyTorch 不带 CUDA（装的是 CPU 版或 macOS 版）`）。用不了的照样能选，换台机器接着用 |
| 半精度 | 关（默认）/ 开 | 只有 NVIDIA 显卡提速；在 CPU 或 MPS 上会挡下来并说明，不假装在提速 |

- 探测显卡只在**打开面板那一刻**做（`import torch` 不该拖慢每次切页），进程内缓存；「重新探测显卡」按钮强制重探，插上新卡不必重启服务。
- 选了这台机器用不了的设备不会让标注失败：跑之前打一行中文说明退到哪一档（`[warn] NVIDIA 显卡（CUDA）不可用（…），本次改用 Apple 加速（MPS）`），面板里也同时给出这句。
- 换设备**不会**让已标好的图重跑：`device` / `half` 不计入断点续跑的参数指纹，`--imgsz`、`--conf` 这些真正改结果的参数照旧触发重标。
- 命令行等价：`autolabel settings` 看、`autolabel settings --device cuda --half` 改、`--reset` 回默认。优先级是命令行 `--device` > YAML `--config` > 系统设置 > 内置默认。
- **启动参数指定的算力只属于那一个实例**：`review --port 8766 --device cuda` 起的实例不改这份设置，面板顶部会写明「推理设备被启动参数指定为 NVIDIA 显卡（CUDA）：这个实例以它为准，在这里改动只对其它实例生效」。多卡机器就是一块卡开一个端口，谁也不抢谁。

三个入口，任选一个：

1. 顶栏 `⋯` 菜单底部 → **系统设置**（`⌥S`）；
2. `⌘K` 搜「系统设置」，或直接搜「推理设备」「切到白天」这类具体动作；
3. 快捷键 `⌥T` 切昼夜、`⌥=` 放大、`⌥-` 缩小（不改面板，六个页面通用，`?` 速查表里也写着）。

白天不是把背景涂白：底色换暖纸白、主文换墨色、强调色整体压深，发丝线与阴影自动反色。压在照片上的 HUD 和框标签底色**两种主题都保持深色**，里面的字用一组恒定偏亮的颜色，避免白天出现深字压深底。刷新时首屏就按本地偏好定好主题，不会白闪一下。

## 界面骨架

六个页面共用同一套壳层——左侧竖排导航条 + 顶栏（品牌 · 模块切换 · `⌘K` 搜索 · 一个主按钮 · `⋯` 溢出菜单），换页不用重新学一遍。两个标注页多了画布相关的区域：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 页面名 + 五个模块切换 +（标注页）**焦点队列胶囊**（库名 · 帧数 · `待确认 N`，行内 `跳转` 直达下一张要处理的）+ 搜索框（`⌘K`）+ 一个主按钮 `导入素材` + `⋯` 溢出菜单。标注页的 `⋯` 装筛选 / 排序 / 显示项 / 批次或字段·类别管理 / 三个导出；工作台的 `⋯` 装数据集目录、跳到导出区与素材池、`重新读取磁盘`（`R`）；素材池的 `⋯` 装分类管理（`C`）、看批次记录（`B`）、`重新读取磁盘`（`R`）；模型管理的 `⋯` 装当前默认与 `重新读取权重`（`R`）。六页 `⋯` 菜单底部都有**关于**（版本、开发者 `windinchen`（点开是 GitHub 主页）、GitHub 仓库、`检查更新`）和**系统设置**（`⌥S`，外观 + 推理算力） |
| 左导航条 | **只管本页自己的面板开关**：标注页是焦点队列、批量标注（`G`）、字段/类别管理（`1`）；素材池是「按素材看 / 按批次看」这一对视图开关加分类管理（`C`）；工作台和模型管理页没有面板可开，这条上就只剩底部的 `?`（模型管理多一枚「更新目录」）。**导入素材不在这里**——它六页统一在右上角那颗主按钮，以前竖条上还挂过一颗一模一样的，两颗去的是同一个弹层；**模块跳转也不在这里**——五枚同形方框并排、还有一枚永远不亮，反而看不出自己在哪一页。帮助按钮六页同一个 id、同一处接线（姿态页曾经因为 id 不统一点了没反应） |
| 焦点队列（竖排） | 一帧一行：缩略图 + 文件名 + 状态摘要（例如 `待复核 · 3 项标记`），带标记的行右上角有红点；`↑` `↓` 在队列内移动 |
| 画布 HUD | 左下角浮一条：关键点可见性色块 + `N 处待确认` / `无需修改` + `第 N / M`；接受或驳回后从下方升起 **5 秒撤销条**，写着「已接受 · 某帧 · 点撤销退回「待复核」」，点它或按 `U` 就把**那一帧**退回去（同时把画面跳回那一帧，看得见确实撤销了），超时自动消失 |
| 右侧面板 | 上半部可滚动：当前帧信息与 QC 标记（**显示中文名**，例如「左右肢体不一致」「框太小」，鼠标悬停给原始 key 方便对着 `qc/report.md` 查）→ **待办清单** → 目标列表；下半部固定：动作按钮 + 常用快捷键（完整表按 `?`） |

- **待办清单是这一版的核心**：把这一帧真正值得动手的关键点（贴边可能偏出框、被标成遮挡、置信度低于 0.4）按「先修错的、再看可疑的」排序，最多 9 条；编号 1…9 同时画在画布上，当前选中点带编号牌与引线。按 `J` / `K` 逐条跳，清单清空就说明这一帧可以放心 `Q` 接受。
- **目标列表默认只展开当前选中的目标**：七个人 × 十七个点全摊开就没法看了，未展开的行只留一行摘要（均置信度、待办数），点一行就选中并展开它的 17 个关键点。
- `V` 聚焦模式把非选中目标淡去，改重叠人群时省眼力；再按 `V` 恢复。
- 顶栏下面的进度条只在处理过至少一张之后才出现，一张没动时不占位置。
- **版本与更新提示常驻顶栏**：右侧的版本徽标（`v1.2.2` 这样）点开就是 GitHub 仓库；GitHub 上有新版本时徽标染成琥珀色带个圆点，顶栏下面同时挂一条「GitHub 上有新版本 v1.2.3（当前 v1.2.2）· 查看更新 · 知道了」，点**知道了**按版本记住，同一版不再重复提。数字全部来自后端 `autolabel/version.py`，界面上没写死过任何一个版本号；`检查更新` 在 `⋯` → 关于里，`⌘K` 搜「检查更新」「GitHub」也能直达。
- **工作台先回答「下一步做什么」**：行动流按「先能跑起来、再挑毛病」排序，最多三条（没图 → 去导入；缺权重 → 去下载；有帧没复核 → 去复核；没画框 → 去标注；都清完 → 去导出），每条右侧按钮直接过去。数字退成一条六格概览，`素材池`「两库共用」这类实现细节词不再当界面主词，卡片标签统一成「标注库 / 公共配置」。

配色是一层石墨底 + 单一琥珀强调色：琥珀只给「可点的当前项 / 开关开着」，红给驳回/待确认，绿给已接受与完成，蓝给选中目标与「你在这一个模块」。两种「亮起来」不混用——琥珀说这一步该做，天蓝说你已经在这一页 / 选中的是这个。状态词（待复核 / 已修改 / 已接受 / 已驳回）统一由 `common.js` 的一份表提供，三个库共用；写回后端的仍是 `unreviewed` / `edited` / `approved` / `rejected` 原值。

## 导入素材（右上角）

按钮六页都在右上角同一个位置（左侧竖条不再挂第二颗）。在**素材池**页按 `U` 传进来的东西只进池不入库；在三个标注页上传则同时进本库并自动标注（弹层里的「入库后自动标注」可以关掉）。

支持三种入口：拖文件到虚线框、`选择图片`、`选择图片目录`（整个文件夹）、`选择视频`。

可选参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模型 | `yolo11n-pose` | 下拉框分两组。**姿态权重**由「模型管理」的清单生成（含自己放进 `models/` 的自定义权重），选项后实时标注 `已就绪 40.5 MB` / `未下载` / `权重不完整`，未下载的直接置灰选不动（一个都没下载时放开第一条，点了先下再标）；**多模态大模型**列出「模型管理」里配好的本地/云端配置（标注 `已连通` / `测试失败` / `未测试`），选中即用大模型逐图标骨骼。选定后下方紧跟一行中文说明，写这档适合什么场景、精度大概多少 |
| 视频抽帧 | 每 2 秒 1 帧 | 也可每秒 1/2 帧 |
| 最多帧数 | 600 | 单个视频上限，和命令行 `--max-frames` 同一个默认（以前界面 300、命令行 600，同一件事两个数） |
| 入库后自动标注 | 开 | 关掉则只入库 |
| 帧去重 | 只跳过完全相同的帧 | 三档：只跳过完全相同的帧 / 近似去重（画面相近只留 1 张）/ 全部保留。同场景多条录像一起导就用默认，选「近似去重」十成常只剩两三成 |
| 批次名 | 空 | 选填。填了就在导入记录里显示这个名字（例如 `10 月球场采集`），不填按第一个文件名自动命名 |
| 归类到 | 未分类 | 素材分类下拉，选项就是素材池那套分类（六页共一份，不存在各模块各有一套）。选了就在素材落池那一刻打上，不用传完再去素材池框一遍；分类刚好在这期间被人删了也不拦路，素材照常进池，只在任务日志上说一声 |

流程：文件 → `.autolabel/uploads/` → 后台任务（抽帧/入库 → 标注 → QC → 生成坐标）→ 进度条与日志 → 列表自动刷新，临时文件清理。

进度条走的是**真实字节数**（大视频会看见它一点点涨，不会一直卡在 1/N），一次传几十个文件时按已传字节合计。日志区只保留**最后 400 条**，更早的折叠成一行「更早 N 条已折叠」——长任务的日志全留在页面上会越滚越卡；点「清空」是真的清空，后续追加不会把刚清掉的又写回来。

这批帧如果之前已经传过（`images/` 里已有），不必重传：弹层里的 **从素材池添加** 会列出还没进本库的素材，勾选后直接引用同一份文件入库，并在本库记一条「从素材池添加 N 个 · …」的导入记录。快捷键 `W` 打开上传弹层，`Esc` 依次关素材池 → 上传弹层。素材整个不要了去 `/pool` 删，别在标注页删。

## 批量姿态标注（快捷键 `G`）

「导入素材」是姿态页**唯一**能触发自动标注的口子，于是两件事没路走：勾了「只入库不标注」传进来的图想补标、换了档更重的权重想把库里重标一遍——以前只能把素材整批重传，重传要重新过去重抽帧，还容易和已经人工复核过的标签打架。

现在这一页和另两个出框页一样有批量面板（`G` 或顶栏 `批量姿态标注`）：

| 项 | 说明 |
| --- | --- |
| 权重 | 与「导入素材」同一个下拉框、同一批选项（姿态权重 + 多模态配置），不另开一套可选清单 |
| 置信度 | 关键点低于这个值按「遮挡」记，不删点 |
| 范围 | **只补没标过的**（默认）/ 整个姿态库 / 当前筛选结果——「当前筛选结果」就是给「刚导进来的那 20 张」准备的 |
| 最多张数 | 填 0 = 不限；先拿 20 张试权重是常见做法 |
| 覆盖已标注的骨骼 | 默认不勾：同参数已标过的、人工点过「接受」的、手工改过骨骼的都原样留着。勾上则一起重标 |

面板里能看到进度条、逐行日志、「清除任务」和「导出 YOLO 训练集」，任务同时出现在顶栏任务条与 `⌘K` 的任务列表里，产出的批次在主页归到「姿态标注」一组，批次名写着「批量姿态标注 N 个 · …」。


## 清除任务

上传弹层里的红色 **清除任务** 按钮（任务运行时才亮）和顶部绿色进度条右侧的 **清除任务**，都可以一键停掉当前任务；点击后弹确认框，`确定` / 回车执行，`取消` / `Esc` 放弃。

- 排队中的任务：立即删除，同时删掉它在 `.autolabel/uploads/` 里的临时文件。
- 正在标注的任务：等当前这张图标完再停（推理中途强杀会留下半截索引），已写入的标注全部保留，并照常重新生成 `coords/` 坐标文件。
- 已经跑完的历史记录一并从任务列表里清掉，界面日志会写明「N 个任务正在取消 · M 个排队任务已删除」。
- 取消无法回退到"继续跑"，想补完剩下的图片直接再点一次「开始上传并标注」或命令行 `label <数据集> --resume` 即可（断点续跑会跳过已标好的）。

注意：

- 后台同一时刻只跑一个标注任务，避免反复加载模型；多任务会排队。
- 任务进行期间 `接受/驳回/新增/撤销` 按钮暂时锁住，完成后自动解锁并刷新列表。
- 点过「清除任务」后按钮会变成「取消中…」并置灰，等当前图片跑完才会真正结束并刷新列表。
- 单文件默认上限 1024 MB，用 `--max-upload-mb` 调整。
- 「帧去重」默认只跳过完全相同的帧；改成**近似去重**会连画面相近的帧一起丢掉，`入库 N 帧` 小于抽出帧数属正常，完成消息会写明跳过了多少、按什么频率取样。

## 素材池（`/pool`）

**素材归池，标注归库**：`images/` 里的文件、素材的分类、进池的来处归素材池（账本 `.autolabel/pool.json`），三个标注库只存「我引用了这张图」和标注结果。于是传素材时不必先决定给哪个模块用，也不怕在 A 库删图带走 B 库的标注。

顶部五张卡按「先看池、再看三个库、最后看还欠多少复核」排：素材（`images/` 里的份数，删这里才是真删）、占用、还没入库（三个模块里都看不到，要用就去那个模块点「从素材池添加」）、几个库共用（删的时候会问你是退一个库还是整批删）、分类。再下面一条分类条给出每个分类的张数，`未分类` 是虚拟分类、不落库。

- **两种视图**：按素材看（缩略图网格，卡片写尺寸体积、被哪几个库引用、属于哪个分类）和按批次看，`B` 来回切。批次记录两份账一起列——**导入的**（从这页进的、从三个标注模块进的）和**标注的**（每个模块跑过的那一轮批量标注）都算，每行徽标写成「导入 · 素材池」「标注 · 姿态标注」，旁边一个类型筛选（全部 / 只看导入 / 只看标注），带几个素材、现在还在池里几个都写出来。只进了池的批次点开看到的是文件名、体积与归类，那批素材本来还没进任何库，没有复核状态可写。张数不都按库索引数：后续标注批次会把同一批素材改挂到自己名下，导入批次要按素材身上盖的来处章数，否则「43 个素材」会显示成 0 个。
- **筛选**：入库情况（全部 / 还没入库 / 被某个库引用）、来源批次、文件名与来源视频名搜索、`全选这一屏`。三个下拉与搜索框都只改当前这一屏的显示，不动数据。
- **分类**（`C`）：分类跟着素材走、只存一份，三个模块看到的分类永远一致；删掉一个分类，底下的素材退回未分类，一张都不会被连带删掉。上限 40 个分类、名字 24 字以内——分类是给人扫一眼的，不是拿来建目录树。
- **加进模块**：勾一批素材 → 底部选目标模块 → 「加进这个模块」，只建引用不复制文件，同时在目标库记一个认领批次（`A` 是同一件事）。「加进模块」的下拉只列三个标注库，素材池自己不进这个列表。
- **删素材看的是「还有哪些库在用」**：只有池独占（没进任何库）的素材才是真删文件；已经进了库的素材，确认框会先列出它在哪几个库还有引用，再让你选「只从本库移除」还是「连素材一起删」。批次被删空会自动消失，不会在列表里挂着 0 张的空行。
- **删批次分两种落场**：不勾「连原图文件一起删」是**整批退回模块外**——只摘掉标注库的引用，素材留在池里，这条记录也留着标成「已退回模块外」，来处不丢、改主意随时再挑进来；勾上才是真删，`images/` 里的文件、账本条目、这条记录一次清干净。以前两种落场都顺手把素材身上的来处摘掉，结果那批素材当场变成「没有批次」：看不出从哪来，也再没法按这批筛出来删。勾到标注批次时确认框会多写一句「这一轮标出来的结果也会一起摘掉」。
- **删错了点「捞回上次删除」**：批次区右下角那颗按钮，旁边写清捞的是哪一次、几张、其中几张还能装回。每次删除都在 `.autolabel/deleted/` 留快照（索引条目 + 三个库各自的标签原文），捞回来是标签文件、索引条目、批次记录一起装回，「已退回模块外」恢复成已完成，导入批次的来处章重盖一遍；原图文件已经删掉的会跳过（装回来只是索引里多一条指向空气的记录）。命令行对应 `autolabel batches <数据集> --restore [快照名]`。没有可捞的快照时按钮不点亮。
- 进度条与「还在导入中」：抽帧任务没跑完之前这批素材删不掉（不然进度和账本对不上），确认框直接说要等它跑完。
- 快捷键：`U` 导入、`C` 分类管理、`B` 切批次视图、`A` 把选中的加进目标模块、`R` 重新读取磁盘、`Esc` 取消勾选。

命令行等价操作：`python3 -m autolabel pool <数据集>` 看池子里都有谁、`pool --add images/a.jpg --lib detect` 认领到某个库。

## 门户的概览数字

- 行动流下面是五格概览：素材池、姿态库、提示词库、检测库、等你复核，小字给已标 / 带标记 / 框数。数字一律从当前磁盘现算，模块卡片上各自的数字只从自己库里算。以前这里还挂第六格「导入批次」，可批次归素材池管，摆在门户等于两处看同一个东西，删了。
- **「等你复核」的口径只有一份**：后端 `/api/dataset` 的 `review` 字段一次算清（`pose_pending` / `prompt_pending` / `detect_pending` = 没接受也没驳回的帧，`pose_flagged` / `prompt_flagged` / `detect_flagged` = 其中机器自己报了问题的），门户照抄，三个复核页的默认队列与 `qc` 报告用的是同一条线。以前门户自己数一遍，姿态库数「所有没定论的」、提示词库只数「带标记的」，拼出来的数没人信。「两个模型结论一致」这类**正向标记不算待确认**，它排在标记区最后、染成绿色。
- 三个标注库 + 素材池是四张入口卡，卡上只写这个库的规模与进度，**不再各带一个导入按钮**（导入统一在右上角）。素材池那张卡带「导入素材」「管理素材池」两颗，去的是 `/pool?upload=1` 与 `/pool`。
- **行动流会说清楚是「还没标」还是「标了没复核」**：从素材池刚加进来的库一张都没标，以前写成「有 N 帧本机权重出的框没复核」，点进复核队列却是一片空白；现在这种库写「有 N 帧本机权重还没跑过 → 去标注」，真标过之后才说「没复核 → 去复核」。

## 批次管理（各标注页 `⋯` → 本库批次）

批次这张表**跟着库走**：姿态页只管姿态库、提示词页只管提示词库、目标检测页只管检测库，标题写明「本库批次 · 只影响 XX 标注库」，素材归属去 `/pool` 看。姿态页的批次入口原来在左侧竖条上占一格，和「导入素材」「批量标注」挤在一起看不出区别，现在收进 `⋯` 菜单，快捷键 `B` 照旧。

按批次列出：名称、时间、来源、文件、图片数 / 已标注 / 人体数或框数 / 待复核数、状态（已完成 / 标注中 / 已取消 / 失败）。没有批次信息的历史数据统一归到「未分组（历史导入）」，同样可以整批删除。

| 操作 | 效果 |
| --- | --- |
| 勾选 + 「删除所选」 | 删除这些批次在本库的图片、标签、QC 叠加图、复核历史与批次记录，删除前弹确认框；素材是否真删由下面的「连素材文件一起删」决定 |
| 「只看这批」 | 主列表只显示该批次的图片，顶部出现筛选标签，点一下取消 |
| 「全选」/「刷新」 | 一次勾选所有批次 / 重新读取统计 |

删除细节：

- 删除前会在 `.autolabel/deleted/<时间戳>.json` 写快照，内含索引字段与标签原文，误删可照快照人工恢复（界面里没有一键恢复）。
- 删完会自动重算 `coords/` 坐标文件和 QC 报告（原本已生成过才重算），训练集不会出现已删图片的残留行。
- 正在标注的批次不允许删除，先点「清除任务」等它停下。
- 勾选「连素材文件一起删」时，素材只在其余两个库都不再引用它时才真删，否则只摘本库引用；只删记录保留图片时，池账本会把这张素材补记回去（否则同一批图再传一次认不出重复，会落双份）。
- 命令行等价操作：`python3 -m autolabel batches <数据集>` 查看（`--lib pose/objects/detect` 单看一个库），`--delete <批次ID>` 删除，`--keep-files` 只删记录保留图片，`--delete-images images/a.jpg --lib detect [--mode lib|purge]` 按张删。

## 提示词标注页（`/objects`）

复核物品检测框的地方，完整说明见 `09-提示词标注.md`。画布上的操作：

| 操作 | 做法 |
| --- | --- |
| 补画漏掉的目标 | 在**空白处**按下拖动，新框字段取右侧「绘制字段」下拉框的当前值 |
| 移动框 / 改大小 | 框内拖动 / 拖角点 |
| 删除标错的框 | 选中按 `X`，或点右侧框列表那行的删除 |
| 改字段 | 右侧框列表每行的字段下拉框（画错类不用删了重画） |
| 缩放 / 平移 | 滚轮 / 空格 + 拖动 |

壳层与姿态标注页完全一致：竖排焦点队列、画布 HUD 与 5 秒撤销条、`⋯` 菜单里的筛选与三个导出、命令面板和速查表都在同样的位置，`导入素材` 也在顶栏（配合 `W`）。

快捷键：`⌘K` 命令面板 / `?` 本页速查表 / `Q` 接受 / `E` 驳回 / `←` `→`（或 `A` `D`）翻页 / `F` 跳到下一张待复核 / `↑` `↓` 队列内上下移动 / `U` 或 `⌘Z` 撤销上一次保存（会先弹确认） / `X`、`Delete`、`0` 删除选中框 / `[` `]` 切换选中框 / `Z` 适应窗口 / `G` 打开批量提示词标注 / `W` 导入素材 / `1` 打开字段管理 / `P` 回姿态标注页 / `M` 跳到模型管理 / `Esc` 关闭弹层。

注意数字键在两页含义不同：姿态页 `0/1/2` 是关键点可见性，提示词页 `0` 是删框、`1` 是字段管理——两页的速查表也各说各的。

带 `⌘` / `Ctrl` 的组合里，**除了 `⌘K`（命令面板）和 `⌘Z`（撤销）**都归浏览器与系统：`⌘A` 全选、`⌘D` 收藏、`⌘F` 页内查找、`⌘J` 下载、`⌘B` 书签栏、`⌘1…9` 切标签页，标注页不再顺手翻页或改关键点可见性。`⌥`（Option）那几个是外观键（`⌥T` 昼夜、`⌥=` / `⌥-` 字号），输入框里打字时不会触发。

「字段管理」弹层里新建的字段会同时进 `data.yaml` 的类名和模型提示词；「批量提示词标注」提交后走任务队列，顶部任务条能看进度，也能「清除任务」。

本页右上角还有 **导入素材**（快捷键 `W`）：这条链路属于提示词库自己，图片和目录直接入库、视频先抽帧，然后按勾选的字段逐图问多模态大模型出检测框，**不跑 YOLO-pose**，产出的批次在主页归到「提示词标注」一组。只入库不标注就取消勾选「入库后自动标注」，之后再从「批量提示词标注」里跑。

弹层里的 **从素材池添加** 是给「这批帧姿态库已经传过」准备的：列出 `images/` 里还没进提示词库的素材，勾选后直接引用同一份文件入库（不重传、不占双份磁盘），并建一个「素材池」批次方便日后整批回退。顶栏会写明「提示词库 N 张（素材池另有 M 张可添加）」。详见 `09-提示词标注.md`。

## 目标检测标注页（`/detect`）

非姿态的目标检测都在这里：本机 YOLO **检测 / 分割 / 旋转框**权重按它自带的类别表出框，人工只删错框、补漏框。完整口径见 `11-目标检测.md`。

这一页和提示词标注页是**同一个前端**（`objects.js` 读一张库配置表服务两页），壳层、画布操作、焦点队列、撤销条、导出全都一样，唯一的差别是**先选权重、再勾权重认识的类别**：

1. **导入素材**（`W`）——本库自己的上传口，图片 / 目录 / 视频都能进，入库后直接可标；也能「从素材池添加」认领别处已入库的帧，不重传、不占双份磁盘。
2. **类别管理**（`1`）——三步：选权重（下拉框只列能用在本库的检测 / 分割 / 旋转框权重，姿态权重列在下方并写明为什么用不了）→ 看它自带哪些类别（英文名 + 中文名 + 类别号 + 类别表规模，支持搜索 / 全选 / 反选 / 清空）→ **导入所选**进本库类别表。不确定自己写的词这个权重认不认识，点旁边的 **先试词**：
拿当前这张图问一次，一个词一行回你最高分与下一步（换权重 / 降阈值 / 换图），**只读不写数据**。
3. **批量目标检测标注**（`G`）——按勾选的类别逐张出框，进度条写明用的哪个权重、多少个类别、共多少张。默认**跳过**三种图：同参数已标过的、人工点过「接受」的、人工手工画过框的；要连它们一起重标就勾「覆盖已有框」。
4. **复核**——删错框、拖动改大小、拖空白补漏框、改类别、`Q` 接受 / `E` 驳回，`F` 跳下一张待复核。
分割权重落的**轮廓能手工拖点**：选中带轮廓的框后，实心点是顶点（拖它改形状）、空心点是边中点
（拖它在那条边上加一个点）、`Alt + 点` 删点（最少留 3 个），松手后方框自动收成轮廓的新外接框。第一次改某张图的框会先备份原件到 `.autolabel/detect/originals/`，`U` / `⌘Z` 能退回。
5. **导出**——`⋯` 菜单里的坐标 CSV / JSONL（链接带 `lib=detect`）与 YOLO 训练集（框带轮廓时自动按 segment 口径写，`data.yaml` 标 `task: segment`）。

快捷键与提示词标注页一致：`⌘K` 命令面板 / `?` 速查表 / `Q` 接受 / `E` 驳回 / `←` `→`（或 `A` `D`）翻页 / `F` 下一张待复核 / `X`、`Delete`、`0` 删框 / `[` `]` 切换框 / `Z` 适应窗口 / `U` 或 `⌘Z` 撤销 / `G` 批量目标检测标注 / `W` 导入素材 / `1` 类别管理 / `O` 跳提示词标注 / `P` 回姿态页 / `M` 模型管理；轮廓不走快捷键，鼠标直接拖点。

和提示词页容易混的两点，界面上都写明白了：

- **顶栏常驻说明条**写着「本机 YOLO 权重按自带类别出框」，并给出「要标权重不认识的东西去提示词标注」的入口；提示词页对应写着「多模态大模型按你写的字段描述找物品」。两页长得太像，不讲清楚一定走错门。
- **词不一样**：这一页管的是「类别」（来自权重自带类别表，导入本库时分配永不复用的类别号），提示词页管的是「字段」（你自己写的名字 + 描述提示词）。同一个 `1` 键，一边开「类别管理」，一边开「字段管理」。

换权重时同名类别继续用同一个号，先前标好的框不会指错东西；只有新权重认不出的类别会落空，任务完成消息会写明「该权重认不出 xxx」，回类别管理按新权重重勾一遍即可。

## 模型管理（`/models`）

独立页面，分三块：**模型目录**、**模型列表**、**多模态大模型**。复核页不再有模型弹层，按 `M` 或点顶部导航过来。完整说明见 `08-模型管理.md`。

**目录顶部是一条搜索框**：输 `yolo11`、`姿态`、`分割` 这类关键词就能搜五种任务（姿态 / 目标检测 / 实例分割 / 旋转框 / 分类）的模型，左边「任务」下拉框再筛一类，结果卡片给中文介绍、参数量、预计体积、自带类别表、在本机的状态和一颗「下载」；卡片右边那句常驻说明写着这份目录来自官方哪一版清单，右上「更新目录」联网核对官方最新档位。勾「联网搜 GitHub」会把官方仓库里的自制权重一起列进来（只给「打开 / 复制」，不代下）。

**模型目录**：默认只列本机已下载的模型（官方完整目录 160 档，关掉「只看已下载」或搜一下就全出来），加上登记过的本地模型与多模态配置。每行前面是一枚**任务标签**（人体姿态 / 目标检测 / 实例分割 / 旋转框 / 图像分类，开放词表另加一枚「开放词表·填词」），后面是中文名、中文说明、参数规模、精度、预计/实际体积、关键点集或自带类别表、适合场景，末尾是状态标签（可用 / 未下载 / 文件不完整 / 不兼容）。

| 操作 | 效果 |
| --- | --- |
| 「任务」下拉框 | 只看一类任务（姿态 / 检测 / 分割 / 旋转框 / 分类）；下方写明「共 N 个 · 各任务就绪 x/y」 |
| 「只看已下载」开关 | 默认开着，只留本机已有的模型；一搜关键词或筛任务就自动放开，下方补一句「另有 N 个未下载没显示」 |
| 「下载」 | 未下载的模型直接下，进度沿用下面「模型列表」区块的行内进度条 |
| 「更新目录」 | 联网核对官方最新发布：新档位连中文介绍一起补进来、体积改正，缓存进 `configs/models.json`；断网只说一句原因，目录不动 |
| 「取消登记」 | 只出现在自己登记的本地模型上；文件留原地 |
| 「登记本地模型」 | 只给仓库外的权重用：填路径（可再填中文名），只记路径不搬文件；官方权重拷进 `models/` 不用登记 |
| 「设为XX默认」 | 在下面的**模型列表**里设，不在目录卡片上：姿态行给「设为姿态标注默认」，检测 / 分割 / 旋转框行给「设为目标检测标注默认」，已经是默认的那枚写着「默认用于XX」 |

- 与当前数据集关键点数量对不上的模型会直接标「不兼容/暂不可用」，并写清「当前数据集 X 是 17 关键点，该模型输出 26 关键点…」，这类模型在上传弹层里选了也会被拦下。
- 标注页的两个模型下拉框只摆**本机已下载**的权重：没下载的不进下拉框（免得点了才开始下几百 MB），刚在「模型管理」下好的那档，回标注页摊开面板就能选到。
- 「下载记录了什么」有据可查：URL、镜像、SHA256 期望/实际值与是否一致、字节数、临时文件名、耗时、成败，命令行 `models --info <ID>` 能看最近 3 条。
- 面板底部写明登记表、权重目录、API Key 文件三个路径，换机器时该拷哪份一目了然。

**模型列表**：只列 `models/` 里真有权重文件的那几档，每行给**任务标签 + 实际占用大小 + 它该管的标注模块默认**，外加下载残留的半截文件和勾选删除。这块管的是**文件与默认**，上面的「模型目录」管的是**信息与下载**。

| 操作 | 效果 |
| --- | --- |
| 「下载」/「重新下载」 | 走镜像拉权重，行内实时显示 `下载中 3.0/50.7 MB`，完成后自动刷新状态与上传面板下拉框 |
| 输入框 + 「下载」 | 拉任意文件名（如 `yolo11l-pose.pt`），不用回命令行 |
| 勾选 + 「删除所选」 | 删除权重文件（连同一并清掉 `.part` / `.bad` 残留），弹确认框，写明释放多少 MB |
| 「刷新」 | 重新读取目录，自己拷进 `models/` 的权重这样识别 |

- 删权重不影响任何已标注数据，下次用到时会自动重下。
- 正在标注的任务用到的权重删不掉，会提示先「清除任务」。
- 命令行等价：`python3 -m autolabel models`（详见 `02-命令行参考.md`）。

**多模态大模型（可选）**：把本地或云端的多模态大模型连接信息存成配置。保存后它们会出现在「导入素材」的模型下拉框里，选中即用大模型标骨骼；不选则继续走 YOLO-pose。

| 字段 | 说明 |
| --- | --- |
| 预设 | Ollama / LM Studio / vLLM / OpenAI / 通义千问 VL / 自定义（OpenAI 兼容），选完自动填地址和模型名 |
| 名称、类型、超时、备注 | 名称用于列表显示；类型分本地服务 / 云端 API；超时 1–300 秒 |
| 服务地址 | OpenAI 兼容地址，例 `http://localhost:11434/v1`；漏了协议头会自动补 `http://` |
| API Key | 本地一般留空；云端填 `sk-…`。**只写入不回显**，明文单独存 `~/.autolabel/secrets.json`，配置文件里只留引用名，界面只显示掩码，留空表示不修改 |
| 回复上限 | 单次回复的 token 上限（64–32768，默认 4096）。思考型模型给太小会回空正文 |
| 送图最长边 | 送出去的图片压到多少像素（256–4096，默认 1024）。调小省 token 与时间 |
| 强制 JSON 模式 | 端点支持时打开，请求带 `response_format`，少一类「模型没返回 JSON」的失败 |

| 按钮 | 效果 |
| --- | --- |
| 保存并测试 | 存盘后立刻验证连通性，结果写进这条配置（`可用 4 ms` 或错误原因） |
| 仅保存 / 新建 / 清空 | 存盘不测试 / 清掉表单开始新建一条 |
| 列表里的 测试 / 编辑 / 设为默认 / 删除 | 单项重测 / 回填表单 / 切换默认配置 / 删除（弹确认框） |

测试失败不会报错弹窗，而是给出可照着做的下一步，比如「连不上 http://localhost:11434/v1：本地服务没启动？Ollama 先跑 `ollama serve`」、「401 未授权：API Key 不对或没有该模型权限」、「404 找不到接口：检查服务地址是否完整（多数服务要写成 …/v1）」。

用多模态大模型标注时注意：

- 每张图一次网络请求，本地 8B 级视觉模型实测 25–40 秒/张，进度条走得慢属正常；任务日志开头会写明用的是哪条配置。
- 下拉框里选「测试失败」的配置也能提交，但多半会失败，任务日志会写出原因。
- 大模型给的骨骼坐标精度不如 YOLO-pose（同一张测试图 4 个人有时只出 2 个），所以每张都会打 `vlm_labeled` 标记，整批进人工复核清单，索引里 `labeled_by` 记成 `vlm:<配置ID>`。
- 单张失败不中断整批，计入失败数并继续下一张。

## 下载坐标

右上角 `⋯` 菜单里的 `坐标 CSV`（宽表）与 `坐标 JSONL`，点击即按当前磁盘上最新标签现场生成并下载，默认排除 `rejected`。字段含义见 `03-坐标文件说明.md`。不想翻菜单就在命令面板（`⌘K`）里搜「导出」。

紧挨着它们的是 `YOLO 训练集` 按钮：产物是**目录**（`images/{train,val}` + `labels/{train,val}` + `data.yaml` + `manifest.json`），浏览器没法直接下载，所以点一下由后端现场生成。默认 2:1 切 train/val、剔掉已驳回的图。验证集成员按图片路径哈希定，**同一张图不会因为后来导入了新图就换到训练集去**，两次导出的指标可以对比。图片默认用**硬链接**放进导出目录，压成 zip 或拷去别的机器都能直接训（导出提示里会写明「图片用硬链接 / 直接拷贝 / 软链接」）；要换这一档在顶栏齿轮「系统设置 → 推理与导出 → 导出训练集的图片」，选「软链接」时导出会额外提醒一句这份产物压缩后图片会变空壳。

因为产物是目录、路径又不可能在提示条里住下，导出过一次之后顶栏下面会出现一行「上次导出」：时间 + 完整路径 + 训练/验证张数，右边三个按钮 **在访达中显示**、**复制路径** 和 **复制训练命令**（后者给的是整条 `yolo pose train data=.../data.yaml model=yolo11s-pose.pt epochs=100 imgsz=640`）。这一版之前它一直常驻、写着「还没有导出过」白占一行，现在没导出过就不出现。这条数据来自 `/api/dataset` 的 `exports_recent`（扫 `exports/` 目录，最近 8 份），刷新页面、重启服务都还在，不用怕提示消失。门户的两行导出里也各带一份自己那套的「上次导出」。

「提示词标注」与「目标检测标注」两页是同样一套三件套（`坐标 CSV` / `坐标 JSONL` / `YOLO 训练集`，类别名各取自己的登记表——提示词页取字段登记表，目标检测标注页取本库类别表），批量标注弹层里也留着同一个导出按钮。两页的坐标链接共用 `/api/prompt/coords`，靠 `lib=detect` 分流，不带这个参数导出的永远是提示词库那份。工作台把三条链路并成三行：人体骨骼（姿态标注）、检测框（提示词标注）、检测框（目标检测标注），每行各自一份「上次导出」，都能单独导出自己的训练集。骨骼与两份检测框是三套独立产物，互不覆盖，也别混用。

## 启动对账

导入或标注跑到一半被打断（重启复核服务、断电、强杀进程），图片副本可能已经落盘但索引还没保存，界面上看着像素材凭空消失，批次还会一直显示"标注中"。复核服务启动时会自动对账：

- 把 `images/` 里已落盘、索引缺席的图片补回索引，挂到那个中断的批次上，状态仍是未复核；
- 把无人认领的"标注中"批次判定为 **已中断**（批次管理里能看到），已入库的图片与标注保留；
- 用 `--keep-files` 删批次而留在磁盘上的文件不会被当成孤儿重新长回来；
- 索引有记录但原图没了的条数会在工作台提示条和启动日志里写明。

中断批次里没跑完的图，重新上传一次即可；补回来的数量在工作台顶部黄色提示条里能看到。

## 状态与筛选

后端存的仍是 `unreviewed` → `edited` / `approved` / `rejected` 四个原值，界面上统一显示中文：待复核 / 已修改 / 已接受 / 已驳回。表只在 `common.js` 里定义一份，三个库共用，不会再各写各的。

筛选挪进了顶栏 `⋯` 菜单，默认 **「待复核」**，口径是「还没定论的」= 未复核 **+ 已修改**——改过但还没接受的帧不会从队列里消失，而已驳回的帧不再回来占位（想在清单里连已定论的一起看：命令行 `qc --include-reviewed`）。完整选项：待复核 / 仅带标记 / 已修改 / 已接受 / 已驳回 / 全部（提示词标注页多一项「未标注」）。

顶栏胶囊上的 `待确认 N` 与本库焦点队列的条数一致：姿态库按「带 QC 标记或整体置信度低于 0.4」算，提示词库按「带标记或还没出过检测框」算。右侧待办清单里那一帧的条目数（`N 处`）是更细的粒度：具体到哪个关键点值得动手。
