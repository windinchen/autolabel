# 复核界面指南

```bash
python3 -m autolabel review datasets/demo        # 默认 http://127.0.0.1:8765
python3 -m autolabel review datasets/demo --port 9000 --max-upload-mb 4096
```

纯标准库 HTTP 服务 + 原生 Canvas 前端，无构建步骤、不联网。界面是本地单用户工具，别公网暴露。

## 页面结构：一套壳 · 四个页面

一个服务四个页面，共用同一个数据集目录，左侧竖排导航条和顶栏模块切换随时跳转：

| 地址 | 模块 | 干什么 |
| --- | --- | --- |
| `/`（工作台） | 门户 | **“下一步”行动流**（最多三条，带直达按钮）、五格概览数字（图片文件 / 姿态库 / 提示词库 / 等你复核 / 导入批次）、两个标注库入口、两套导出入口、**批次管理**（两个模块的批次统一管，能展开到逐张删除） |
| `/pose` | 姿态标注 | 人体骨骼的自动标注与人工复核（`/review` 是改名前的老地址，同一页） |
| `/objects` | 提示词标注 | 用描述提示词让多模态大模型找物品，产出检测框；删错框、补画漏框都在这里 |
| `/models` | 模型管理 | 模型目录、姿态权重文件、多模态大模型配置 |

- 三个模块写各自的标签目录，互不覆盖：骨骼写 `labels/`，物品框写 `prompt_labels/`。
- 工作台的统计一律从当前磁盘上的索引现算，不做缓存，跟复核页看到的数一致。
- 姿态标注页按 `O` 跳提示词标注，按 `M` 跳模型管理；提示词标注页按 `M` 同样跳模型管理。

## 快捷键

以下为**姿态标注**页的按键，提示词标注页的按键见下文同名小节。

| 按键 | 作用 |
| --- | --- |
| `⌘K` / `Ctrl+K` | 命令面板：动作、筛选、按文件名跳帧都能搜（也可点顶栏搜索框） |
| `?` | 本页快捷键速查表（两个库的数字键不同，各查各的） |
| 拖动关键点 | 微调位置（bbox 会自动撑住所有可见点） |
| `J` / `K` | 待办清单下一条 / 上一条（编号与画布上的编号一致） |
| `↑` / `↓` | 在左侧焦点队列里上下移动 |
| `V` | 聚焦模式：非选中目标淡成背景，只盯当前这个改 |
| `0` / `1` / `2` | 选中点设为 忽略 / 遮挡 / 可见 |
| `Q` / `E` | 接受 / 驳回当前图，自动翻页并在画布下方弹 5 秒撤销条 |
| `←` / `→`（或 `A` / `D`） | 上一张 / 下一张 |
| `F` | 跳到下一张待确认（带 QC 标记或整体置信度偏低的图） |
| `X` | 删除选中目标 |
| `[` / `]` | 切换选中目标 |
| `Alt+方向键` | 像素级微调（`Shift` 加大步长） |
| 滚轮 / 空格拖 | 缩放 / 平移 |
| `Z` | 适应窗口 |
| `U` | 撤销一次修改 |
| `B` | 打开批次管理 |
| `W` | 打开导入素材弹层 |
| `O` | 跳到「提示词标注」模块 |
| `M` | 跳到「模型管理」模块（原来是本页弹层，现在是独立页） |
| `⌥T` | 白天 / 夜晚切换（也可 `⌘K` 搜「外观」，或 `⋯` → 外观） |
| `⌥=` / `⌥-` | 字号放大 / 缩小（小 · 标准 · 大 · 特大 四档） |
| `Esc` | 关闭当前弹层 / 菜单 / 命令面板 |

改动防抖 600ms 自动写回标签；首次修改前把自动标注原件备份到 `.autolabel/originals/`，另有最近 10 个历史快照（`.autolabel/history/`），`U` 逐级回滚。

## 外观：白天 / 夜晚 · 字号

四个页面共用一套外观设置，记在**本机浏览器**（`localStorage` 的 `autolabel.appearance`）：切页、刷新、重启服务都保持，换浏览器或换电脑需要重设一次。

| 项 | 档位 | 说明 |
| --- | --- | --- |
| 主题 | 跟随系统（默认）/ 白天 / 夜晚 | 「跟随系统」跟着 macOS 的浅色深色自动切换，系统改了界面立刻跟着改 |
| 字号 | 小 / 标准（默认）/ 大 / 特大 | 整站缩放（0.92 / 1 / 1.12 / 1.26 倍），画布上的框标签与 HUD 一起缩放 |

三个入口，任选一个：

1. 顶栏 `⋯` 菜单底部的**外观**（两排分段选择器，当前档高亮）；
2. `⌘K` 搜「外观」，选「切到白天 / 切到夜晚 / 跟随系统」；
3. 快捷键 `⌥T` 切昼夜、`⌥=` 放大、`⌥-` 缩小（四页通用，`?` 速查表里也写着）。

白天不是把背景涂白：底色换暖纸白、主文换墨色、强调色整体压深，发丝线与阴影自动反色。压在照片上的 HUD 和框标签底色**两种主题都保持深色**，里面的字用一组恒定偏亮的颜色，避免白天出现深字压深底。刷新时首屏就按本地偏好定好主题，不会白闪一下。

## 界面骨架

四个页面共用同一套壳层——左侧竖排导航条 + 顶栏（品牌 · 模块切换 · `⌘K` 搜索 · 一个主按钮 · `⋯` 溢出菜单），换页不用重新学一遍。两个标注页多了画布相关的区域：

| 区域 | 内容 |
| --- | --- |
| 顶栏 | 页面名 + 三个模块切换 +（标注页）**焦点队列胶囊**（库名 · 帧数 · `待确认 N`，行内 `跳转` 直达下一张要处理的）+ 搜索框（`⌘K`）+ 一个主按钮 `导入素材` + `⋯` 溢出菜单。标注页的 `⋯` 装筛选 / 排序 / 显示项 / 批次或字段管理 / 三个导出；工作台的 `⋯` 装数据集目录、跳到导出区与批次管理、`重新读取磁盘`（`R`）；模型管理的 `⋯` 装当前默认与 `重新读取权重`（`R`） |
| 左导航条 | 标注页：焦点队列开关、导入素材、批次管理（姿态页）或字段管理与批量标注（提示词页）、两个模块跳转、快捷键速查（`?`）。工作台与模型管理页同样一条，只是把队列开关换成页内跳转 |
| 焦点队列（竖排） | 一帧一行：缩略图 + 文件名 + 状态摘要（例如 `待复核 · 3 项标记`），带标记的行右上角有红点；`↑` `↓` 在队列内移动 |
| 画布 HUD | 左下角浮一条：关键点可见性色块 + `N 处待确认` / `无需修改` + `第 N / M`；接受或驳回后从下方升起 **5 秒撤销条**，点 `撤销 U` 或直接按 `U` 反悔，超时自动消失 |
| 右侧面板 | 上半部可滚动：当前帧信息与 QC 标记（**显示中文名**，例如「左右肢体不一致」「框太小」，鼠标悬停给原始 key 方便对着 `qc/report.md` 查）→ **待办清单** → 目标列表；下半部固定：动作按钮 + 常用快捷键（完整表按 `?`） |

- **待办清单是这一版的核心**：把这一帧真正值得动手的关键点（贴边可能偏出框、被标成遮挡、置信度低于 0.4）按「先修错的、再看可疑的」排序，最多 9 条；编号 1…9 同时画在画布上，当前选中点带编号牌与引线。按 `J` / `K` 逐条跳，清单清空就说明这一帧可以放心 `Q` 接受。
- **目标列表默认只展开当前选中的目标**：七个人 × 十七个点全摊开就没法看了，未展开的行只留一行摘要（均置信度、待办数），点一行就选中并展开它的 17 个关键点。
- `V` 聚焦模式把非选中目标淡去，改重叠人群时省眼力；再按 `V` 恢复。
- 顶栏下面的进度条只在处理过至少一张之后才出现，一张没动时不占位置。
- **工作台先回答「下一步做什么」**：行动流按「先能跑起来、再挑毛病」排序，最多三条（没图 → 去导入；缺权重 → 去下载；有帧没复核 → 去复核；没画框 → 去标注；都清完 → 去导出），每条右侧按钮直接过去。数字退成一条五格概览，`素材池`「两库共用」这类实现细节词不再当界面主词，两个库的卡片标签改成「标注库 / 公共配置」。

配色是一层石墨底 + 单一琥珀强调色：琥珀只给「可点的当前项」，红给驳回/待确认，绿给已接受与完成，蓝给选中目标。状态词（待复核 / 已修改 / 已接受 / 已驳回）统一由 `common.js` 的一份表提供，两个库共用；写回后端的仍是 `unreviewed` / `edited` / `approved` / `rejected` 原值。

## 导入素材（右上角）

支持三种入口：拖文件到虚线框、`选择图片`、`选择图片目录`（整个文件夹）、`选择视频`。

可选参数：

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 模型 | `yolo11n-pose` | 下拉框分两组。**姿态权重**由「模型管理」的清单生成（含自己放进 `models/` 的自定义权重），选项后实时标注 `已就绪 40.5 MB` / `未下载` / `权重不完整`，未下载的直接置灰选不动（一个都没下载时放开第一条，点了先下再标）；**多模态大模型**列出「模型管理」里配好的本地/云端配置（标注 `已连通` / `测试失败` / `未测试`），选中即用大模型逐图标骨骼。选定后下方紧跟一行中文说明，写这档适合什么场景、精度大概多少 |
| 视频抽帧 | 每 2 秒 1 帧 | 也可每秒 1/2 帧 |
| 最多帧数 | 300 | 单个视频上限 |
| 入库后自动标注 | 开 | 关掉则只入库 |
| 保留近重复帧 | 关 | 勾上后不做感知去重（动作快、画面差异小的视频用） |
| 批次名 | 空 | 选填。填了就在「批次管理」里显示这个名字（例如 `10 月球场采集`），不填按第一个文件名自动命名 |

流程：文件 → `.autolabel/uploads/` → 后台任务（抽帧/入库 → 标注 → QC → 生成坐标）→ 进度条与日志 → 列表自动刷新，临时文件清理。

这批帧如果提示词库之前已经传过（`images/` 里已有），不必重传：弹层里的 **从素材池添加** 会列出还没进姿态库的素材，勾选后直接引用同一份文件入库并建「素材池」批次。快捷键 `W` 打开弹层，`Esc` 依次关素材池 → 上传弹层。

## 清除任务

上传弹层里的红色 **清除任务** 按钮（任务运行时才亮）和顶部绿色进度条右侧的 **清除任务**，都可以一键停掉当前任务；点击后弹确认框，`确定` / 回车执行，`取消` / `Esc` 放弃。

- 排队中的任务：立即删除，同时删掉它在 `.autolabel/uploads/` 里的临时文件。
- 正在标注的任务：等当前这张图标完再停（推理中途强杀会留下半截索引），已写入的标注全部保留，并照常重新生成 `coords/` 坐标文件。
- 已经跑完的历史记录一并从任务列表里清掉，界面日志会写明「N 个任务正在取消 · M 个排队任务已删除」。
- 取消无法回退到"继续跑"，想补完剩下的图片直接再点一次「开始上传并标注」或命令行 `label <数据集> --resume` 即可（断点续跑会跳过已标好的）。

注意：

- 后台同一时刻只跑一个标注任务，避免反复加载模型；多任务会排队。
- 任务进行期间 `接受/驳回/新增/撤销` 按钮暂时锁住，完成后自动解锁并刷新列表。
- 点过「清除任务」后按钮会变成「取消中…」并置灰，等当前图片跑完才会真正结束并刷新列表。
- 单文件默认上限 1024 MB，用 `--max-upload-mb` 调整。
- 感知去重会丢弃近重复帧，日志里 `入库 N 张` 小于抽出帧数属正常。

## 批次管理（门户 `/`）

「姿态标注」和「提示词标注」是**两个独立的库**：各自一套索引、批次表、标签目录和撤销快照，只有 `images/` 素材池共用。主页底部把**两个库的批次放在一起管**，不用再回各自页面找。

- 行动流下面是一条五格概览：图片文件（`images/` 里的份数）、姿态库、提示词库、等你复核、导入批次，小字给已标 / 带标记 / 框数。数字一律从当前磁盘现算，模块卡片上各自的数字只从自己库里算。
- 每个库的卡片只留一个入口 `导入图片 / 视频`（跳到该模块直接摊开上传弹层）。认领另一侧已传过的素材改在上传弹层里做（`从素材池添加`），门户不再放第二个入口，免得同一个动作有两个地方。
- 批次汇总一行：`姿态标注 N 批 / N 张 / 已标 N 张` 与 `提示词标注 N 批 / N 张 / 已标 N 张 · N 框`；右侧「模块」下拉框可按全部 / 姿态 / 提示词筛选。
- 每行一个批次：模块徽章、批次名、时间·来源·素材·导入张数（跨库复用会写「复用素材池 N」）、**骨骼 N/M 张 · N 人**与**检测框 N/M 张 · N 框**两套进度、状态、`看文件`、`去复核`（提示词批次跳 `/objects`，姿态批次跳 `/pose`）。同一素材被两个库都引用时，这两列按跨库视图取数，**行内小计与展开清单逐张加起来一定对得上**。
- 「看文件」展开这个批次的逐张图片：文件名、导入时间、尺寸、体积、骨骼状态/人数、检测框状态/框数，再加一枚「另一个库也在用 / 只在这个库」的提示；行尾按钮默认**从本库移除**，行首勾选后可用底部按钮批量处理。
- 删除粒度由底部的 **「连素材文件一起删」** 勾选框决定：不勾=只把图从它所属的那个库移除（素材文件和另一个库的标注都不动，按钮写「从本库移除」）；勾上=两个库一起摘引用并删掉 `images/` 里的素材（按钮变「删素材」）。整批删除同口径，素材只在对面库不再引用时才真删。
- 批次行首的勾选框配合「删除所选批次」整批删；被删空的批次记录会自动移除，不会在列表里挂着 0 张的空行。没有批次信息的历史数据归到各库自己的「未分组」行，可以单独清。
- 删前在 `.autolabel/deleted/` 写快照（含两库标签原文和来自哪个库），`coords/` 坐标与 QC 报告随之重算；批次还在标注中时拒绝删除，先回对应模块点「清除任务」。确认框支持 `Enter` 确定 / `Esc` 取消。

命令行等价操作：`python3 -m autolabel batches <数据集>` 看列表（`--lib pose/objects` 单看一个库），`--delete <批次ID>` 整批删，`--delete-images images/a.jpg --lib objects [--mode lib|purge]` 按张删，`pool <数据集>` 看素材池、`pool --add` 认领到某个库。

## 批次管理弹层（姿态页，快捷键 `B`）

姿态标注页里的老弹层继续可用，**只列姿态库的批次**（提示词库的批次在主页或 `/objects` 管），按批次列出：名称、时间、来源、文件、图片数 / 已标注 / 人体数 / 待复核数、状态（已完成 / 标注中 / 已取消 / 失败）。没有批次信息的历史数据统一归到「未分组（历史导入）」，同样可以整批删除。

| 操作 | 效果 |
| --- | --- |
| 勾选 + 「删除所选」 | 删除这些批次的图片、标签、QC 叠加图、复核历史与批次记录，删除前弹确认框 |
| 「只看这批」 | 主列表只显示该批次的图片，顶部出现绿色筛选标签，点一下取消 |
| 「全选」/「刷新」 | 一次勾选所有批次 / 重新读取统计 |

删除细节：

- 删除前会在 `.autolabel/deleted/<时间戳>.json` 写快照，内含索引字段与标签原文，误删可照快照人工恢复（界面里没有一键恢复）。
- 删完会自动重算 `coords/` 坐标文件和 QC 报告（原本已生成过才重算），训练集不会出现已删图片的残留行。
- 正在标注的批次不允许删除，先点「清除任务」等它停下。
- 命令行等价操作：`python3 -m autolabel batches <数据集>` 查看，`--delete <批次ID>` 删除，`--keep-files` 只删记录保留图片。

## 提示词标注页（`/objects`）

复核物品检测框的地方，完整说明见 `09-提示词标注.md`。画布上的操作：

| 操作 | 做法 |
| --- | --- |
| 补画漏掉的目标 | 在**空白处**按下拖动，新框字段取右侧「绘制字段」下拉框的当前值 |
| 移动框 / 改大小 | 框内拖动 / 拖角点 |
| 删除标错的框 | 选中按 `X`，或点右侧框列表那行的删除 |
| 改字段 | 右侧框列表每行的字段下拉框（画错类不用删了重画） |
| 缩放 / 平移 | 滚轮 / 空格 + 拖动 |

壳层与姿态标注页完全一致：竖排焦点队列、画布 HUD 与 5 秒撤销条、`⋯` 菜单里的筛选与三个导出、命令面板和速查表都在同样的位置，`导入素材` 也在顶栏（配合 `W`）。

快捷键：`⌘K` 命令面板 / `?` 本页速查表 / `Q` 接受 / `E` 驳回 / `←` `→`（或 `A` `D`）翻页 / `F` 跳到下一张待复核 / `↑` `↓` 队列内上下移动 / `U` 撤销上一次保存（会先弹确认） / `X`、`Delete`、`0` 删除选中框 / `[` `]` 切换选中框 / `Z` 适应窗口 / `G` 打开批量提示词标注 / `W` 导入素材 / `1` 打开字段管理 / `P` 回姿态标注页 / `M` 跳到模型管理 / `Esc` 关闭弹层。

注意数字键在两页含义不同：姿态页 `0/1/2` 是关键点可见性，提示词页 `0` 是删框、`1` 是字段管理——两页的速查表也各说各的。

「字段管理」弹层里新建的字段会同时进 `data.yaml` 的类名和模型提示词；「批量提示词标注」提交后走任务队列，顶部任务条能看进度，也能「清除任务」。

本页右上角还有 **导入素材**（快捷键 `W`）：这条链路属于提示词库自己，图片和目录直接入库、视频先抽帧，然后按勾选的字段逐图问多模态大模型出检测框，**不跑 YOLO-pose**，产出的批次在主页归到「提示词标注」一组。只入库不标注就取消勾选「入库后自动标注」，之后再从「批量提示词标注」里跑。

弹层里的 **从素材池添加** 是给「这批帧姿态库已经传过」准备的：列出 `images/` 里还没进提示词库的素材，勾选后直接引用同一份文件入库（不重传、不占双份磁盘），并建一个「素材池」批次方便日后整批回退。顶栏会写明「提示词库 N 张（素材池另有 M 张可添加）」。详见 `09-提示词标注.md`。

## 模型管理（`/models`）

独立页面，分三块：**模型目录**、**姿态权重文件**、**多模态大模型**。复核页不再有模型弹层，按 `M` 或点顶部导航过来。完整说明见 `08-模型管理.md`。

**模型目录**：13 档可下载模型 + 登记过的本地模型 + 多模态配置，一份清单看全。每行给出中文名、中文说明、参数规模、精度、预计/实际体积、关键点集与速度、适合场景，末尾是状态标签（可用 / 未下载 / 文件不完整 / 不兼容）。

| 操作 | 效果 |
| --- | --- |
| 顶部筛选下拉框 | 只看姿态 / 只看多模态；旁边写明「共 N 个 · 可用 M 个」 |
| 备注输入框 + 「保存备注」 | 给这个模型写一句人话（比如「只在内网机器下」「显存吃紧别用」），清空即删除；存在 `configs/models.json` |
| 「下载」 | 未下载的模型直接下，进度沿用下面「姿态权重」区块的行内进度条 |
| 「设为默认」 | 按能力分别记默认值，姿态与多模态互不影响 |
| 「取消登记」 | 只出现在自己登记的本地模型上；文件留原地 |
| 「登记本地模型」 | 填仓库外的权重路径（可再填中文名与备注），只记路径不搬文件 |

- 与当前数据集关键点数量对不上的模型会直接标「不兼容/暂不可用」，并写清「当前数据集 X 是 17 关键点，该模型输出 26 关键点…」，这类模型在上传弹层里选了也会被拦下。
- 「下载记录了什么」有据可查：URL、镜像、SHA256 期望/实际值与是否一致、字节数、临时文件名、耗时、成败，命令行 `models --info <ID>` 能看最近 3 条。
- 面板底部写明登记表、权重目录、API Key 文件三个路径，换机器时该拷哪份一目了然。

**姿态权重文件（YOLO-pose）**：列出 `models/` 目录里已有的权重和界面预置的 n/s/m，显示体积、更新时间、是否就绪，以及下载残留的半截文件。这块管的是**文件**，上面的「模型目录」管的是**信息与说明**。

| 操作 | 效果 |
| --- | --- |
| 「下载」/「重新下载」 | 走镜像拉权重，行内实时显示 `下载中 3.0/50.7 MB`，完成后自动刷新状态与上传面板下拉框 |
| 输入框 + 「下载」 | 拉任意文件名（如 `yolo11l-pose.pt`），不用回命令行 |
| 勾选 + 「删除所选」 | 删除权重文件（连同一并清掉 `.part` / `.bad` 残留），弹确认框，写明释放多少 MB |
| 「刷新」 | 重新读取目录，自己拷进 `models/` 的权重这样识别 |

- 删权重不影响任何已标注数据，下次用到时会自动重下。
- 正在标注的任务用到的权重删不掉，会提示先「清除任务」。
- 命令行等价：`python3 -m autolabel models`（详见 `02-命令行参考.md`）。

**多模态大模型（可选）**：把本地或云端的多模态大模型连接信息存成配置。保存后它们会出现在「导入素材」的模型下拉框里，选中即用大模型标骨骼；不选则继续走 YOLO-pose。

| 字段 | 说明 |
| --- | --- |
| 预设 | Ollama / LM Studio / vLLM / OpenAI / 通义千问 VL / 自定义（OpenAI 兼容），选完自动填地址和模型名 |
| 名称、类型、超时、备注 | 名称用于列表显示；类型分本地服务 / 云端 API；超时 1–300 秒 |
| 服务地址 | OpenAI 兼容地址，例 `http://localhost:11434/v1`；漏了协议头会自动补 `http://` |
| API Key | 本地一般留空；云端填 `sk-…`。**只写入不回显**，明文单独存 `~/.autolabel/secrets.json`，配置文件里只留引用名，界面只显示掩码，留空表示不修改 |
| 回复上限 | 单次回复的 token 上限（64–32768，默认 4096）。思考型模型给太小会回空正文 |
| 送图最长边 | 送出去的图片压到多少像素（256–4096，默认 1024）。调小省 token 与时间 |
| 强制 JSON 模式 | 端点支持时打开，请求带 `response_format`，少一类「模型没返回 JSON」的失败 |

| 按钮 | 效果 |
| --- | --- |
| 保存并测试 | 存盘后立刻验证连通性，结果写进这条配置（`可用 4 ms` 或错误原因） |
| 仅保存 / 新建 / 清空 | 存盘不测试 / 清掉表单开始新建一条 |
| 列表里的 测试 / 编辑 / 设为默认 / 删除 | 单项重测 / 回填表单 / 切换默认配置 / 删除（弹确认框） |

测试失败不会报错弹窗，而是给出可照着做的下一步，比如「连不上 http://localhost:11434/v1：本地服务没启动？Ollama 先跑 `ollama serve`」、「401 未授权：API Key 不对或没有该模型权限」、「404 找不到接口：检查服务地址是否完整（多数服务要写成 …/v1）」。

用多模态大模型标注时注意：

- 每张图一次网络请求，本地 8B 级视觉模型实测 25–40 秒/张，进度条走得慢属正常；任务日志开头会写明用的是哪条配置。
- 下拉框里选「测试失败」的配置也能提交，但多半会失败，任务日志会写出原因。
- 大模型给的骨骼坐标精度不如 YOLO-pose（同一张测试图 4 个人有时只出 2 个），所以每张都会打 `vlm_labeled` 标记，整批进人工复核清单，索引里 `labeled_by` 记成 `vlm:<配置ID>`。
- 单张失败不中断整批，计入失败数并继续下一张。

## 下载坐标

右上角 `⋯` 菜单里的 `坐标 CSV`（宽表）与 `坐标 JSONL`，点击即按当前磁盘上最新标签现场生成并下载，默认排除 `rejected`。字段含义见 `03-坐标文件说明.md`。不想翻菜单就在命令面板（`⌘K`）里搜「导出」。

紧挨着它们的是 `YOLO 训练集` 按钮：产物是**目录**（`images/{train,val}` + `labels/{train,val}` + `data.yaml` + `manifest.json`），浏览器没法直接下载，所以点一下由后端现场生成。默认 2:1 切 train/val、剔掉已驳回的图。

因为产物是目录、路径又不可能在提示条里住下，导出过一次之后顶栏下面会出现一行「上次导出」：时间 + 完整路径 + 训练/验证张数，右边三个按钮 **在访达中显示**、**复制路径** 和 **复制训练命令**（后者给的是整条 `yolo pose train data=.../data.yaml model=yolo11s-pose.pt epochs=100 imgsz=640`）。这一版之前它一直常驻、写着「还没有导出过」白占一行，现在没导出过就不出现。这条数据来自 `/api/dataset` 的 `exports_recent`（扫 `exports/` 目录，最近 8 份），刷新页面、重启服务都还在，不用怕提示消失。门户的两行导出里也各带一份自己那套的「上次导出」。

「提示词标注」页是同样一套三件套（`坐标 CSV` / `坐标 JSONL` / `YOLO 训练集`，检测框那套类别名取字段登记表），批量标注弹层里也留着同一个导出按钮。工作台把两条链路并成两行，每行都能单独导出各自的训练集。骨骼与检测框是两套独立产物，别混用。

## 启动对账

导入或标注跑到一半被打断（重启复核服务、断电、强杀进程），图片副本可能已经落盘但索引还没保存，界面上看着像素材凭空消失，批次还会一直显示"标注中"。复核服务启动时会自动对账：

- 把 `images/` 里已落盘、索引缺席的图片补回索引，挂到那个中断的批次上，状态仍是未复核；
- 把无人认领的"标注中"批次判定为 **已中断**（批次管理里能看到），已入库的图片与标注保留；
- 用 `--keep-files` 删批次而留在磁盘上的文件不会被当成孤儿重新长回来；
- 索引有记录但原图没了的条数会在工作台提示条和启动日志里写明。

中断批次里没跑完的图，重新上传一次即可；补回来的数量在工作台顶部黄色提示条里能看到。

## 状态与筛选

后端存的仍是 `unreviewed` → `edited` / `approved` / `rejected` 四个原值，界面上统一显示中文：待复核 / 已修改 / 已接受 / 已驳回。表只在 `common.js` 里定义一份，两个库共用，不会再各写各的。

筛选挪进了顶栏 `⋯` 菜单，默认 **「待复核」**，口径是「还没定论的」= 未复核 **+ 已修改**——改过但还没接受的帧不会从队列里消失。完整选项：待复核 / 仅带标记 / 已修改 / 已接受 / 已驳回 / 全部（提示词标注页多一项「未标注」）。

顶栏胶囊上的 `待确认 N` 与本库焦点队列的条数一致：姿态库按「带 QC 标记或整体置信度低于 0.4」算，提示词库按「带标记或还没出过检测框」算。右侧待办清单里那一帧的条目数（`N 处`）是更细的粒度：具体到哪个关键点值得动手。
