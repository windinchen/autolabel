# UI 交互重构方案

这份是**方案 + 实施记录**：诊断与分期仍是提案，**P0 已于 2026-10-17 落地**（见下文「P0 已落地」）。现状以代码为准（界面在 `autolabel/static/`，接口在 `autolabel/review.py`），操作说明见 `04-复核界面指南.md`。此后每期改完都要同步回 `04`/`08`/`09`/`README`。（**2026-10-18 追加**：壳层现在是**五个页面**——新增的「目标检测」`/detect` 与提示词标注页共用同一份 `objects.js`，只差一张库配置表；操作与理由见 `11-目标检测.md`。本文里的「四页 / 两个库」是当时那期的口径，保留不改写。）

## 结论先行

一句话：**把「4 个并列页面 + 顶栏堆按钮 + 弹层套弹层」改成「一个应用壳 + 一条复核动线 + 一个命令面板」。**

六个主张：

1. **入口去重靠命令面板，不靠更大的顶栏。** 所有动作（导出、导入、切批次、复制训练命令、跳到某张图）都能用 `⌘K` 搜到，顶栏因此可以只留一个主操作。
2. **术语只有一套。** 未复核 / 已修改 / 已接受 / 已驳回，两个库用同样的词、同样的键；「素材池」「两库共用」「摘引用」这些实现细节不再当界面主词。
3. **破坏性操作用「撤销条」而不是「确认框」。** 删图、删批次、清除任务点完立刻生效，底部给 5 秒可撤销；不可撤销的（覆盖标签、删素材文件）才弹确认，并且写明快照落在哪。
4. **长任务反馈只有一个地方：顶部任务胶囊。** 进度、阶段、失败原因、重试、清除全在胶囊展开的抽屉里；顶栏那条光秃秃的进度条和弹层内的日志一起收掉。
5. **画布负责回答「这帧哪儿可疑」。** QC 命中的关键点高亮、可疑点之间 `Tab` 跳转，非可疑点淡出；文字标记退到检查器里。
6. **快捷键分层且可查。** `g` 前缀做导航、数字键永远只表示可见性、`?` 随时打开当前页快捷键速查。老键位保留一个「经典快捷键」开关兜底。

## 真实数据集首屏（2026-10-17 晚 · 本轮唯一一处后端改动）

新界面第一次拿到真实数据集上跑，暴露的不是配色问题，而是「网页起不起来」：纯姿态数据集（从没跑过提示词标注）没有 `prompt_*` 条目可搬，`migrate` 判定无事可做，`.autolabel/objects/index.json` 始终缺失，`ReviewStore` 抛 `FileNotFoundError`，`autolabel review` 直接崩。补了 `library.ensure_objects_index()`（迁移时缺索引就补一本空的，`migrate` 输出「新建 …」）。同时清掉界面里最后一批英文黑话：14 个骨骼标记 + 9 个检测框标记统一显示中文名（`common.js` 的 `FLAG_LABEL` / `flagLabel()`），原始 key 退到悬停提示里。

防回归：`tests/test_library_split.py` 保证纯姿态数据集迁移后索引存在且 `ReviewStore` 可构造；`tests/test_review_shell.py` 保证后端新增标记 key 时必须给中文标签、两个标注页必须走 `flagLabel()`。全量：`297 passed, 1 skipped`（跳过项缺 ffmpeg）。

仍未做（原 P1 尾巴）：上传弹层 → 底部导入坞、删图 / 删批次确认框 → 撤销条、顶栏任务条 → 胶囊抽屉。防回归测试扩到四页：`tests/test_review_shell.py` 现在要求门户与模型管理必须带 `#rail` / `#palette-modal` / `#help-modal` / `#more-menu`、必须接线 `registerShellCommands` / `initShellChrome` / `shellKeys`，速查表里宣传的单键必须在同页 JS 有 `case`，并禁止门户界面文案再出现那三个实现细节词。全量：`291 passed, 5 skipped`。

## 外观层（2026-10-17 晚 · 白天 / 夜晚 · 四档字号）

外观原本排在 P2，实际用下来属于「第一次长时间复核就一定会要」的那类，提前做完。纯前端，接口一字未动。

- **两套主题 · 四档字号 · 四页通用**：主题 `跟随系统`（默认）/ `白天` / `夜晚`，字号 `小` / `标准` / `大` / `特大`；设置存 `localStorage`（`autolabel.appearance`）。入口三处：`⋯` 菜单底部的分段选择器、`⌘K` 搜「外观」、快捷键 `⌥T` / `⌥=` / `⌥-`。
- **实现走 CSS 变量**：`data-theme` / `data-fs` 两个属性驱动，`:root[data-theme="light"]` 覆盖整套色值，`--fs` 进所有 `font-size` 的 `calc()`。为此把颜色彻底 token 化，`:root` 之外零色值字面量；`app.js` / `objects.js` 的画布改从 `common.js` 的 `canvasPalette()` 取 CSS 变量（按主题与字号缓存），并监听 `appearancechange` 重画。
- **一处值得记下的取舍**：压在照片上的深色底板（HUD、框标签底色）在白天**也保持深色**，但里面的文字改用一组恒定的亮墨 token（`--veil-ink*`、`--c-photo-*`）。第一版直接复用主题的 `--ink-2` / `--amber`，白天立刻露馅——那些色是为读浅色面板而压深的，深字压深底，实拍里 HUD 的「4 处待确认」和画布 `#1 k13/17` 几乎读不出。照片内容不可控，叠加层不跟随主题反转是更稳的选择。
- **首屏不闪**：四个 HTML 在 `</head>` 前内联一小段脚本，渲染前就写好 `data-theme` / `data-fs`；切换时 200ms 过渡，`prefers-reduced-motion` 下跳过。
- **防回归**：`tests/test_review_shell.py` 新增 5 条（四页首屏脚本与控件位齐全、速查表宣传的快捷键写在表里、`font-size` 一条不漏 `var(--fs)`、`:root` 之外不硬编码色值、画布走外观 token、深色底板上的选择器走亮墨）。全量 `302 passed, 1 skipped`。

## 目标与非目标

目标：

- 首次打开到改完第一张图 ≤ 3 步，全程不需要读文档。
- 同一动作只剩一个入口，其余入口一律可在命令面板里搜到。
- 两个库之间切换零重新学习成本（同一套词、同一套键、同一套布局）。
- 1280×800 到 2560 宽都能用，不允许画布高度被非画布控件挤掉。

非目标：

- 不改标注/导出/撤销的落盘格式，不动 `.autolabel/` 目录结构。
- 不做多用户协作、权限、评论。
- 不在本期换构建链（除非拍板选方案 C，见文末）。

## 五个视图

### 1 概览（取代门户）

不再堆八张统计卡，改成**行动流**：顶部三张行动卡按优先级排，每张直接是可点的下一步。

| 卡片 | 触发条件 | 主按钮 |
| --- | --- | --- |
| 有 N 张待复核 | 任一库存在未复核/带标记 | 开始复核 →（进对应队列，直接落在最高优先级那张） |
| 有 N 个任务失败 | 任务队列里有 failed | 查看失败原因 →（打开任务抽屉并定位） |
| 有 M 张未标注 | 已入库无标签 | 去标注 →（选模型后提交） |

行动流下面才是次级信息：两库各自的进度条（同一套状态词）、最近导出（保留现有「上次导出 + 在访达中显示 + 复制训练命令」，这块现在做得好，只是别在四个地方重复）、素材占用。启动对账/孤儿图的黄色提示条改成行动流里的一张卡，不单独占位。

### 2 复核队列（核心，两个库共用一套壳）

- 中栏顶部一条工具条：筛选、排序、批次分组、显示开关。`edited` 补进筛选项，且默认「未复核」包含 edited（改到一半的图不该消失）。
- 胶片条升级为**可切网格/列表的虚拟列表**，带批次分组头（组头显示该批次进度与「只看这批」）。当前是 64×44 缩略图横向滚动，量大时既看不清也定位不了。
- **聚焦模式**（`Tab` 开关）：只描边 QC 命中的关键点/框，其余降到 25% 不透明度；`Shift+Tab` 在可疑点之间跳。这是「只改模型错的那几个点」的正面兑现。
- **批量接受**：范围（本批次 / 当前筛选结果 / 手勾）+ 阈值滑块（如「仅接受无标记且最高分 ≥ 0.6」）。确认层要写明「将接受 N 张，其中 M 张带标记」，执行后给撤销条。目前只能逐张按 `Q`，几百张的批次没有别的办法。
- 接受/驳回保持 `Q`/`E` 且自动翻页不变。

### 3 素材与批次（合并三处为一张表）

门户底部区块 + 姿态页 `B` 弹层 + 门户模块卡合并成一个视图：批次行 → 展开素材行，一张表管完两个库。

术语改写：

| 现在 | 改成 |
| --- | --- |
| 素材池 / 从素材池添加 | 已上传过的素材 → 「加进这个标注」 |
| 从本库移除 | 只从这个标注移除 |
| 连素材文件一起删（两个库都移除） | 彻底删除（所有标注 + 文件） |
| 复用素材池 N | 没有新增文件（已存在） |
| 两库共用素材 | 另一个标注也在用 |

删除一律「立刻生效 + 底部撤销条」，撤销条里写明快照路径。只有「彻底删除」需要确认（要真删文件），确认框里直接列出影响面。

### 4 模型

保留页面，但把「模型目录」和「姿态权重文件」两块合成一张表：模型信息是行，下载状态/体积/残留是同一行的状态列——现在同一个权重在两处各说一遍，还得来回对照。多模态配置的长表单从常驻改成点「新建/编辑」后从右侧滑出的抽屉，列表才不会被表单挤到底部。

### 5 导入（弹层 → 底部导入坞）

- 任意位置拖文件 → 底部升起导入坞，画布不被遮挡，能边看边改。
- 两步流：第 1 步只有拖拽区和已选文件列表；第 2 步才出现处理方式（模型、抽帧密度、是否自动标注）。抽帧密度/最多帧数/去重/批次名收进「高级」折叠，默认只露模型和「自动标注」开关。
- 进度和日志不再待在弹层里，交给顶部任务胶囊；坞本身提交后立刻收成一行「已提交 · 查看进度」。
- 「从素材池添加」不再是弹层里的按钮，而是导入坞第 1 步的一个标签页：「上传新文件 / 选已上传过的」。

## 统一交互系统

### 命令面板（`⌘K` / `Ctrl+K` / `/`）

覆盖动作 + 对象两类条目：动作如「导出坐标 CSV」「导出 YOLO 训练集」「复制训练命令」「只看这批」「打开模型管理」；对象如「跳到 12 张带 no_person 的图」「跳到批次 10 月球场采集」。复用现有的 `INPUT/SELECT/TEXTAREA` 早退守卫（`app.js:443`），避免在输入框里打字母误触发。

这是入口去重的正解：不是把按钮排得更好看，而是让「所有入口」都能被搜到，从而允许顶栏只留一个主操作。

### 状态与反馈

- 状态词固定四个：`未复核` / `已修改` / `已接受` / `已驳回`；后端值（`unreviewed`/`pending`、`edited`、`approved`、`rejected`）在前端一层 `STATUS_LABEL` 映射里收口，两个库共用。
- 提示分三级：成功（toast 2 秒）、警示（常驻直到关闭）、错误（必带「下一步」文案——模型管理里已经这么做了，推广到全局，别再出现裸 500）。
- 破坏性操作 → 底部撤销条（5 秒）；不可撤销 → 确认框 + 快照路径。
- 空状态必须给动作按钮，不是「试试切换筛选」这种没有出口的话。
- 首次进入给三步一次性气泡引导（存 localStorage），`⌘K` 里可随时重放。

## 接口增量

原则：既有 `/api/*` 契约一字不改，只加两个聚合接口，缺了它们这一期就退回「前端硬扫全量索引」。

| 接口 | 用途 | 服务于 |
| --- | --- | --- |
| `GET /api/actions` | 返回行动卡所需数据：各库待复核数、失败任务、未标注数、最近导出、对账异常 | 概览行动流（现在门户靠 `dataset_payload` 现算，凑不出「失败任务」这一维） |
| `POST /api/batch-approve` | `{lib, images[] \| filter, min_score?, skip_flagged?}` → 返回实际改动清单与可撤销句柄 | 批量接受（现在只能逐张 `POST /api/status`，几百次请求且无法整体撤销） |

可选第三个：`GET /api/jobs?since=` 支持增量拉取，任务抽屉就不必每次全量 `snapshot()`。

## 风险

- **书签与外链**：`/review` → `/pose` 的老地址要保留（`review.py:874`）。若 P1 改成单入口壳，必须继续支持 `/pose`、`/objects`、`/models` 深链，否则文档里的链接全断。
- **肌肉记忆**：改键是老用户唯一的抱怨点。缓解：`Shift+A` 而非复用裸键；`[` `]` 保留别名；提供经典模式开关。
- **零构建的天花板**：无组件复用、无类型检查，`shell.js` 会超过 1000 行。可接受（现有 `app.js` 已 1152 行、`objects.js` 1250 行），但要提前把状态收进单一 `state` 对象、把渲染做成纯函数，否则 P2 会失控。
- **测试面**：`tests/` 现有 289 项只覆盖到 Web 层接口（`test_prompt_web.py`、`test_review_export.py`），前端逻辑无测试。P2 加接口时一并补测；前端冒烟建议单独确认是否引入 Playwright，别在 P0 顺手塞进 `requirements.txt`。
- **文档同步**：`04-复核界面指南.md` 的整节（页面结构表、快捷键表、上传面板、批次管理）会被这份方案改写，实施每期都要同步改它和 `08`/`09`/根 `README` 的界面段落，否则文档立刻失真。P0 这轮的 `04` / `09` / 根 `README` 已同步。

## 视觉与交互风格选型

第一轮给了四套皮肤级方案（深色密集 / 亮色卡片 / 影院 / 看板），评审结论是「没有设计过的感觉」：只换了配色与栅格，没有字阶、没有成套图标、没有签名细节。第二轮按「先定设计系统、再画界面」重做，两方向共用一套骨架，差异只在材质。

| 方向 | 材质与色 | 字体 | 签名细节 | 适合 |
| --- | --- | --- | --- | --- |
| **石墨 Graphite** | 石墨底 `#0E1113` + 骨白正文，琥珀 `#F5A524` 为唯一强调色，只标「下一步」与可疑点；接受=玉绿、驳回=珊瑚红 | Space Grotesk（标题与小字母间距标签）+ Inter（正文）+ IBM Plex Mono（一切数字） | 检测框只画四角括号不画整框；可疑点带光晕并用编号连到检查器；进度是分段「骨节」条；界面发丝线，浮层才给投影 | 长时间复核、键盘优先、大吞吐 |
| **纸本 Index** | 暖纸 `#F6F3ED` + 墨色正文，朱红 `#C33C1E` 为唯一强调色，可疑点用淡黄底纹 | Fraunces（图注与品牌，含斜体）+ Inter（清单）+ IBM Plex Mono（编号与坐标） | 画布当展品图版：细线装裱 + 下方图注；画布上的朱红圆形编号与右侧待办清单一一对应，编号即处理顺序 | 带新人、低频标注、要给外人看 |

两方向共用的骨架：4px 间距阶（4/8/12/16/20/24/32）、每方向只有一个强调色、16px 网格 1.5 描边圆头的一套图标、半径只用 2/4/7/全圆、动效只有 120ms（按压）/200ms（面板）/500ms（界面让位画布）三段并支持 `prefers-reduced-motion`。

选型时建议同时定下：强调色只有一个、所有数字走等宽、可疑点必须从画布一路可见到列表与统计。这三条比配色更能决定「像不像被设计过」。

## 拍板结果（2026-10-17）

1. **技术栈**：留在「零构建 + 原生 JS + 标准库 HTTP」。P0 已按这条做完，`python3 -m autolabel review` 打开还是即用；没引入 `npm`、没引入网络字体（本地工具常年离线，字体得跟着包走）。
2. **两个队列是否合并**：**不合并**。姿态与提示词各自一条焦点队列，只统一外壳、术语与键位；数字键在两页含义不同这一事实写进两页各自的速查表，并在界面上注明。
3. **改键是否接受**：**只加不减**。新增 `⌘K` / `?` / `J` / `K` / `V` / `↑` `↓`，`0/1/2`、`X`、`[` `]`、`Z`、`A` `D` 等老键位原样保留，因此方案里设想的「经典快捷键开关」不必做。
4. **视觉方向**：采纳**石墨 Graphite** 的骨架与色板（含四角括号检测框、分段骨节进度、编号连检查器），并把**纸本 Index** 的「编号 ↔ 待办清单」机制搬过来当复核动线的主轴——这是本次唯一被采纳的跨方向组合。

下一期（P1 剩余）建议按「上传弹层 → 底部导入坞」「删图/删批次确认框 → 撤销条」「任务条 → 顶栏胶囊抽屉」三件推进，都是纯前端；P2 的两个接口（`/api/actions`、`/api/batch-approve`）仍未实现，等这两件落地后再评估是否真需要。

## 最左边那条到底放什么（2026-10-19 · v1.4.11）

三个标注页的批量入口补齐之后，竖条彻底没法看了：姿态页那一竖同时出现「焦点队列 / 导入素材 / 批次管理 / 三枚模块跳转 / 帮助」，其中**两枚模块跳转是 `common.js` 兜底代码现插的**，图标全用同一个 `#ic-boxes`、而且永远不点亮——五枚一模一样的方框排在一起，用户问的不是「这个图标是什么意思」，而是「我现在到底在哪一页」。同时「选中」这个状态在系统里被两种颜色表达过：焦点队列开关用琥珀（琥珀=主操作），模块定位也用琥珀（该亮的那一项），语义撞在一起。

这一轮把两件事拆开写死：

| 位置 | 只负责 | 不再做 |
| --- | --- | --- |
| 顶栏中文标签 | 「我在哪个模块」——当前项天蓝描边 + 天蓝底 | 白天主题下只把底色调深一档（和页面底色差不到 5%，等于没标） |
| `⋯` 菜单「去别的模块」 | 跨模块跳转的第二入口（各页 HTML 只留 `#menu-modules` 占位） | 每页自己写死几条 `<a>`，加库漏一页 |
| 左侧 52px 竖条 | **本页自己的弹层**：焦点队列开关 / 导入素材 / 批量标注 / 批次或类别管理；帮助按钮钉在底部 | 模块跳转（整排摘掉），「某页没有某模块入口」这类 bug 从根上没了 |
| 琥珀色 | 下一步、主操作、开关开着 | 表示「你在这页」 |
| 天蓝色 | 选中的对象、当前所在模块 | —— |

图标语义也一并归了类：批次管理=一摞纸、类别/字段管理=带项目符号的列表（新 `#ic-list`）、姿态标注=小人（新 `#ic-pose`）、提示词标注=标签（新 `#ic-prompt`）、目标检测标注=方框、模型管理=立方体、工作台=房子（新 `#ic-home`）。**一枚图标只表示一件事**，跨页不许复用于不同含义。

同日补齐第三个批量入口：姿态页原本只有「导入素材」能触发自动标注，勾了「只入库不标注」的图和换权重想重标的只能整批重传——现在 `G` 开「批量姿态标注」，面板形状、快捷键、任务条、批次命名规则与另两页完全一致，范围能选「当前筛选结果」，后端 `label_dataset(only=...)` 在扫描源头圈范围而不是跑完再挑。
