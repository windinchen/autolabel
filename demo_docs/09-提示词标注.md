# 提示词标注

用「一段描述提示词」换「一批检测框」：你写清楚要标什么物品、什么算这个物品，多模态大模型逐张图去找，产出的框直接能喂 `yolo detect train`。

与「姿态标注」是**两个独立的库**：各自一套索引、批次表、标签目录、原件与撤销快照，删图互不影响，只有 `images/` 素材池共用一份。

| | 姿态标注 | 提示词标注 |
| --- | --- | --- |
| 库名（`--lib`） | `pose` | `objects` |
| 目标 | 人体 + COCO-17 关键点 | 任意物品（你自定义字段） |
| 后端 | YOLO-pose 权重 | 多模态大模型（本地或云端） |
| 标签目录 | `labels/` | `prompt_labels/` |
| 索引 | `.autolabel/index.json` | `.autolabel/objects/index.json` |
| 批次表 | `.autolabel/batches.json` | `.autolabel/objects/batches.json` |
| 原件 / 撤销 | `originals/`、`history/` | `objects/originals/`、`objects/history/` |
| 字段登记表 | — | `.autolabel/fields.json` |
| 任务类型 | `image` / `video` | `prompt`（批量标注）/ `prompt_upload`（上传并标注）/ `pool`（素材池认领） |
| 导出 | `yolo pose train` | `yolo detect train` |
| 复核页 | `/pose` | `/objects` |
| 上传入口 | `/pose` 右上角「导入素材」（`W`） | `/objects` 右上角「导入素材」（`W`） |
| 共用素材 | 两处都能「从素材池添加」：同一帧只落盘一次，两库各持引用 | 同左 |

老数据集（两个模块曾共用一套索引）用 `python3 -m autolabel migrate <数据集>` 一键拆分，幂等，复核服务启动时也会自动做一次。

## 字段：先说清"要标什么"

字段是提示词标注的唯一输入，存在 `<数据集>/.autolabel/fields.json`。一个字段三样东西：

| 字段属性 | 约束 | 用途 |
| --- | --- | --- |
| `name` | 英文字母开头，只含字母/数字/`_`/`-`，≤32 字符 | 模型必须原样回报的类名，也是 `data.yaml` 里的 `names` |
| `label` | 中文显示名，≤40 字符 | 界面与坐标文件里给人看 |
| `prompt_hint` | 描述提示词，≤600 字符 | 告诉模型"什么算这个目标"，写不写差别很大 |

另外两条规则要注意：

- **`class_id` 一旦分配永不复用**：删掉 `bottle`（原 0 号）之后新建的字段会拿 4 号而不是 0 号。好处是历史标签不会因为删字段而错位串类；代价是类别号可能不连续，导出时会自动重映射成连续的 `0..N-1`。
- **上限 80 个字段**：一次请求里字段太多，模型回报的框质量和长度都会掉。真需要更多类别，建议按场景分数据集。

描述提示词怎么写才有效：

- 写**判据**而不是写词。`桌上或手里拿着的塑料水瓶，含纸杯、保温杯` 比 `水瓶` 明显准。
- 写**排除项**。`不含固定在墙上的灭火器`、`不含别人手里的手机`，比事后删框省时间。
- 一条字段一件事。`瓶子和杯子` 拆成两条，之后想调哪条改哪条，签名会变、只重标受影响的图。

界面：`提示词标注` → `字段管理`（新建 / 改显示名 / 改描述 / 删除）。命令行：

```bash
python3 -m autolabel fields datasets/demo --add "bottle=桌上或手里拿着的塑料水瓶，含纸杯、保温杯"
python3 -m autolabel fields datasets/demo --add "backpack=椅上或肩上的背包，不含手提购物袋"
python3 -m autolabel fields datasets/demo --set-label "bottle=水瓶"
python3 -m autolabel fields datasets/demo                 # 看字段表和每个字段的已标框数
python3 -m autolabel fields datasets/demo --delete bottle # 还有框时会拒绝，加 --drop-boxes 连带删框
```

删字段时如果磁盘上还有别的类别号残留（字段早先删过但框还在），界面会提示"孤儿类别号"，`--drop-boxes` 或界面里勾选清理。

## 素材从哪来：自己上传，或直接领用素材池

提示词标注不必借用姿态标注的上传口。`提示词标注` 页右上角 **导入素材**（快捷键 `W`）是本库独立的链路：

1. 选图片 / 选图片目录 / 选视频，或直接把文件拖进虚线框（多个文件按 3 个并发上传，进度写在小弹窗日志里）；
2. 勾要标的字段（可多选）、选多模态配置、抽帧密度、最多帧数、「帧去重」，可填批次名与补充说明；
3. 提交后走 `prompt_upload` 任务：入库（视频先抽帧，默认只跳过完全相同的帧）→ 逐图问多模态大模型 → 写 `prompt_labels/` → 出检测框坐标 → 登记成**提示词库的批次**。

同一批素材如果姿态标注那边已经传过，就别再传一遍：弹层里的 **从素材池添加** 会列出 `images/` 里还没进提示词库的图（顶栏也会提示「素材池另有 M 张可添加」），勾选后直接引用同一份文件进本库，不重传、不复制、不占双份磁盘，并登记成一个「素材池」批次。挑得动大池子靠顶部三条筛选：分类 / 批次 / 找文件名，批次选项按素材的来处章凑（`pool_batch`、`pool_batch_name`），右侧 **顺手归类到** 能在认领的同时把这批素材挪进另一个分类。命令行等价：

```bash
python3 -m autolabel pool datasets/demo --lib objects            # 看池里哪些还没进提示词库
python3 -m autolabel pool datasets/demo --lib objects --add images/a.jpg  # 直接认领
python3 -m autolabel import datasets/demo ~/Pictures/杯子 --lib objects   # 新素材入库，命中池则复用
```

几个要点：

- **不跑 YOLO-pose**，`labels/` 一个字节都不会动；只想入库不标注就取消「入库后自动标注」，之后再从「批量提示词标注」里挑范围跑。
- 只入库时不校验字段和多模态配置，字段还没建也能先把素材丢进来。
- 重复图会被去重跳过，任务会如实写「没有新图入库（可能与已有图片重复…）」，不会假装标了多少张。
- 传完的批次在主页「批次管理」的**提示词标注**分组里，能展开逐张删。默认「从本库移除」只摘提示词库的引用，`images/` 里的素材和姿态库的骨骼标注都不动；勾上「连素材文件一起删」才三个库一起摘掉并删素材文件。细节见 `04-复核界面指南.md`。
- 命令行等价：先 `autolabel import --lib objects`（或 `video --lib objects`、`pool --lib objects --add`）入库，再 `autolabel prompt`，产出完全一致。

## 跑标注

界面：`提示词标注` → `批量提示词标注`，选字段（可多选）、选多模态配置、选范围（仅未标注 / 当前筛选 / 整个数据集）、限张数、是否覆盖已标、补充说明，提交后在顶部任务条看进度，`清除任务` 可停。

```bash
python3 -m autolabel prompt datasets/demo --status              # 看还差多少张
python3 -m autolabel prompt datasets/demo --vlm 本地\ Ollama --limit 20   # 先试跑
python3 -m autolabel prompt datasets/demo --coords --export     # 全量跑完顺手出坐标和训练集
```

- **没指定的不重复跑**：每张图记一个签名（字段集合 + 描述文本 + 多模态配置）。签名没变就跳过，只补新图；改了描述或换了模型，签名变了，相关图会被判定为需要重标（界面上带 `prompt_stale` 标记）。`--overwrite` 强制全部重标。
- **人碰过的图默认不动**：已经点过「接受」（`prompt_status=approved`）或手动画过框（`prompt_manual>0`）的图片，即使签名变了也会被跳过，任务完成消息与命令行汇总里的「人工保护 N 张」就是它。要连这些一起重标，勾界面上的「覆盖已有框」或命令行加 `--overwrite`——重标后人工标记与人工框下标会一并清零，复核状态退回「已编辑」，需要重新过目。
- **补充说明**（`--prompt-extra`）会插在提示词第二行，也计入签名。适合临时加一条全局判据，比如"只标完整出现在画面里的人手里的杯子"。
- **单张失败不拖垮整批**：某张超时/解析失败会打 `vlm_failed` 标记并继续，最后汇总里能看到失败数。
- 每张图一次网络请求，本地 8B 级视觉模型实测 25–40 秒/张，62 张大约要半小时，先用 `--limit` 试跑。

## 复核：删掉标错的，补上没找到的

进 `提示词标注` 页，左侧的**焦点队列**按优先级排好（顶栏 `⋯` 里默认筛「待复核」，还能切 仅带标记 / 已修改 / 已接受 / 已驳回 / 未标注 / 全部），一帧一行写着状态与框数，带标记的有红点。「待复核」的口径与姿态标注页、门户、`qc` 报告完全一致 = **还没定论的帧**（没接受也没驳回），已驳回的帧不再回来占位。壳层与姿态标注页一致：竖排队列、画布左下角 HUD（`N 处待确认` + `第 N / M`）、接受/驳回后弹 5 秒撤销条、`⋯` 菜单里放筛选与三个导出、`⌘K` 命令面板、`?` 速查表。

画布上的操作：

| 操作 | 做法 |
| --- | --- |
| 补画漏掉的目标 | 在**空白处**按下拖动，新框的字段取右侧「绘制字段」下拉框的当前值 |
| 移动框 | 在框**内部**拖动 |
| 改大小 | 拖框的角点 |
| 删除标错的框 | 选中框按 `X`，或点框列表里那一行的删除 |
| 改字段 | 框列表每行的字段下拉框（画错的类不用删了重画） |
| 缩放 / 平移 | 滚轮缩放，空格 + 拖动平移 |
| 撤销 | 按 `U`，回到上一次保存前的框（第一次画完也能撤销回空白）；`Z` 是适应窗口。刚点过 `Q` / `E` 时撤销条还开着，这时按 `U` 撤销的是**那一帧的接受 / 驳回**（状态退回原样并把画面切回那一帧），不会顺手把你画好的框回滚掉 |

人工画的框会打 `manual` 标记，索引里记在 `prompt_manual_boxes`（框的下标）。YOLO 的 5 列标签存不下"这条是人工画的"，所以重读磁盘时靠这个索引键把标记贴回去——**不要手改 `prompt_labels/` 里的行顺序**，下标一错，人工标记就串到别的框上。人工框导出时置信度按 1 计。

快捷键：`⌘K` 命令面板 / `?` 本页速查表 / `Q` 接受 / `E` 驳回 / `←` `→`（或 `A` `D`）翻页 / `F` 跳到下一张待确认（带标记或还没标过框的，与顶栏「待确认 N」同口径）/ `↑` `↓` 队列内上下移动 / `U` 撤销上一次保存（会先弹确认；撤销条开着时先撤销那次接受 / 驳回） / `X`、`Delete`、`0` 删除选中框 / `[` `]` 切换选中框 / `Z` 适应窗口 / `G` 打开批量提示词标注 / `W` 导入素材 / `1` 打开字段管理 / `P` 回姿态标注页 / `M` 跳到模型管理 / `Esc` 关闭弹层。

数字键与姿态标注页不同（那边 `0/1/2` 是关键点可见性），两页的速查表也各说各的；按 `?` 看当前页的。

## 质量标记

| 标记 | 含义 |
| --- | --- |
| `none_found` | 这张一个框都没有：可能确实没有，也可能整张漏标 |
| `small_box` | 框太小（短边不足 12 像素），训练时容易学不动 |
| `edge_box` | 框贴画面边缘，目标可能被裁断 |
| `dup_box` | 同字段两个高度重叠的框，重复标注 |
| `unknown_class` | 标签里有登记表里不存在的类别号 |
| `prompt_stale` | 标注用的字段/描述与当前设置不一致，建议重标 |
| `vlm_failed` | 这次模型没答上（网络/超时/解析失败），框是旧的或缺失 |
| `manual` | 人工补画或重画的框，导出时置信度按 1 计 |

复核优先级由这些标记加权得出，`small_box`/`dup_box`/`vlm_failed` 会排在前面。

目标检测库（`/detect`）共用这套标记，只有两处按来源换了名字，别照抄到检测库上找：
`prompt_stale` → `model_stale`、`vlm_failed` → `model_failed`，另外多一条 `masked`
（这一框出自分割权重，轮廓已随框落盘）。整表见 `11-目标检测.md`。

## 提示词实际长什么样

字段表会被拼成这段（`build_prompt`）：

```
你是图像标注助手。请在图里找出下列目标，每个目标给一个贴边的边界框。
目标字段：
- bottle（水瓶）：桌上或手里拿着的塑料水瓶，含纸杯、保温杯
- backpack（背包）：椅上或肩上的背包，不含手提购物袋
坐标用 0-1000 的整数，表示相对图片宽高的位置：左上角 (0,0)，右下角 (1000,1000)。
field 字段必须严格照抄上面给出的英文字段名，不要自己造词、不要翻译。
框要贴着目标边缘；同一个目标只标一个框；目标之间不要互相重叠成两个框。
看不清、不确定、只是像的目标不要标；被遮挡超过一半的目标不要标；画面里没有就返回空列表。
只输出 JSON，不要任何解释文字，格式：
{"objects":[{"field":"字段名","bbox":[x1,y1,x2,y2]}]}
```

解析这一侧尽量兜住模型的坏毛病：```` ```json ```` 包裹、裸数组、`detections`/`items`/`results` 当外层键、散文里夹 `{}`、`xywh`/`{x1,y1,x2,y2}`/`{cx,cy,w,h}` 三种坐标写法、0-1 小数与 0-1000 整数与像素三种量纲、中文类名和模糊类名（按显示名/包含关系回捞）都能认；认不出的类名进 `guesses` 汇报而不是硬塞；同一目标重复的框按重叠度去重；越界坐标 clamp 回画面。模型只回一段纯文字时按"没找到"处理，不猜框。

## 产物与导出

- 标签：`<数据集>/prompt_labels/<同名>.txt`，每行 `class_id cx cy w h`（归一化，永远 5 列）。
- 坐标文件：`<数据集>/coords/<tag>/` 下 `objects.csv`（宽表）、`objects_long.csv`、`objects.jsonl`，列含 `class_name` / `display_name` / `bbox_*` / `box_flags` 等。界面「下载坐标」走 `GET /api/prompt/coords?format=csv|jsonl`。
- 训练集：`exports/<tag>-detect/`，`images/{train,val}` + `labels/{train,val}` + `data.yaml`。类别号重映射成连续 `0..N-1`，`data.yaml` 的注释里写明原始类别号；`rejected` 的图默认排除，空图按 `max_empty_ratio`（默认 0.15）掺入当负样本。没进训练集的帧会在提示里写明白（`没收进来的 （prompt_status=rejected 2 张 · 背景图超出比例上限（上限 15%） 3 张）`），`prompt_meta.json` 里逐张留痕。界面上重复点导出不会重复落盘：检测框内容和参数都没变时直接复用最近那份目录，提示「标签没有变化，已复用上次导出」。
- 界面入口有三处，产物同一个：提示词页右上角 `YOLO 训练集`、`批量提示词标注` 弹层里的 `导出数据集`、工作台「检测框」行的 `导出 YOLO 训练集`。都是 `POST /api/prompt/export`，点击后由后端落盘并在提示里给出目录路径。工作台的导出行旁边多了一个**导出范围**下拉框：`剔除已驳回（含未复核）`（默认）/ `只要已接受 · 已修改` / `全部帧`，与命令行 `--only-approved` / `--include-all` 同口径——想在界面里只导人工确认过的帧，不必再回命令行。

```bash
python3 -m autolabel prompt datasets/demo --coords --export --out datasets/demo/exports/bottle-detect
yolo detect train data=datasets/demo/exports/bottle-detect/data.yaml model=yolo11s.pt epochs=100 imgsz=640
```

## 建议节奏

1. 先建 2–3 个字段，描述写细，`--limit 20` 试跑，看框的质量再决定要不要继续加字段。
2. 描述改一轮、再试跑一轮，比一次标完整批更省时间：描述导致的系统偏差在 20 张里就能看出来。
3. 复核优先处理 `small_box` / `dup_box` / `vlm_failed`，这三类是训练收益最高的修正点。
4. 每轮导出后固定 `data.yaml` 交给训练侧，字段增删会让类别号重映射，别手抄 `names`。
