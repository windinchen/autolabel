# 目标检测

非姿态的目标检测标注：本机的 YOLO 权重按**它自带的类别表**出框，人工只在浏览器里删错框、补漏框，导出直接喂 `yolo detect train`。

和「提示词标注」的区别只有一句话，但决定了该用哪个：

| | 提示词标注 | 目标检测 |
| --- | --- | --- |
| 谁出框 | 多模态大模型按**你写的描述**在画面里找 | 本机 YOLO 权重按**它自带的类别表**出框 |
| 类别从哪来 | 你自己定义字段（任意物品） | 权重决定（COCO-80 / 你自训练的 N 类） |
| 联网 | 云端配置要联网，每张一次请求 | 不联网 |
| 速度 | 秒级一张 | 几十毫秒一张 |
| 擅长 | 权重没见过的新物品、语义模糊的目标 | 常见物品、大批量预标注 |
| 界面提示语 | 「多模态大模型按你写的字段找物品」 | 「本机 YOLO 权重按自带类别出框」 |

一句话选择：**权重认识的东西用目标检测（快），权重不认识的东西用提示词标注（灵活）**。两个库共用 `images/` 素材池，同一帧只落盘一次，可以在两个模块间来回标同一批图。

## 三个标注库的分工

| | 姿态标注 | 提示词标注 | 目标检测 |
| --- | --- | --- | --- |
| 库名（`--lib`） | `pose` | `objects` | `detect` |
| 目标 | 人体 + COCO-17 关键点 | 任意物品（你自定义字段） | 权重自带的类别 |
| 后端 | YOLO-pose 权重 | 多模态大模型（本地或云端） | YOLO 检测 / 分割 / 旋转框权重 |
| 标签目录 | `labels/` | `prompt_labels/` | `detect_labels/` |
| 索引 | `.autolabel/index.json` | `.autolabel/objects/index.json` | `.autolabel/detect/index.json` |
| 批次表 | `.autolabel/batches.json` | `.autolabel/objects/batches.json` | `.autolabel/detect/batches.json` |
| 原件 / 撤销 | `originals/`、`history/` | `objects/originals/`、`objects/history/` | `detect/originals/`、`detect/history/` |
| 类别登记表 | —（按关键点，无类别表） | `.autolabel/fields.json` | `.autolabel/detect/classes.json` |
| 记住的选择 | 数据集 `settings` | 签名进索引 | `.autolabel/detect/prefs.json`（上次用的权重 / 类别 / 阈值） |
| 任务类型 | `image` / `video` | `prompt` / `prompt_upload` | `detect` / `detect_upload` |
| 导出 | `yolo pose train` | `yolo detect train`（`exports/*-detect/`） | `yolo detect train`（`exports/*-yolo-detect/`） |
| 复核页 | `/pose` | `/objects` | `/detect` |
| 类别上限 | — | 80 个字段 | 200 个类别 |

三库各自一套索引、批次、标签目录、原件与撤销快照，删图 / 复核 / 撤销互不影响；只有素材池共用。**独立素材库**就是这个意思：`/detect` 有自己的上传口（快捷键 `W`），也能从素材池「认领」别处已经入库的帧，不需要先跑到姿态标注页去上传。

## 界面：`/detect`

一套壳第五个页面（快捷键 `O` 在提示词标注与目标检测之间来回跳）。和提示词标注页唯一的差别是**先选权重、再勾权重认识的类别**：

1. **导入素材**（`W`）——图片 / 目录 / 视频，走本库自己的上传链路，入库后可以直接跑标注。
2. **类别管理**（`1`）——三步：
   - 选权重：下拉框只列**能用在本库**的权重（`models/` 里的检测 / 分割 / 旋转框），姿态权重会被列在下方并写明「这是「人体姿态」权重，检测库用不了；人体骨骼请回姿态标注」。
   - 看它认得出什么：列出该权重自带的类别表（英文名 + 中文名 + 类别号 + 类别表规模，如 COCO-80），支持搜索 / 全选 / 反选 / 清空。
   - 导入所选：勾中的类别进入**本库类别登记表**，同名类别永不换号。
3. **批量目标检测**（`G`）——按勾选的类别逐张出框，进度条上写明用的哪个权重、多少个类别、共多少张。默认**跳过**三种图：同参数已经标过的、人工点过「接受」的、人工手工画过框的；要重标勾「覆盖已有框」。
4. **复核**——删错框、拖框补漏、改类别、接受 / 驳回，`F` 跳下一张待复核。第一次改某张图的框会先备份原件，`⌘Z` / 「撤销」能退回。
5. **导出**——`⋯` 菜单里：检测框坐标 CSV / JSONL（链接带 `lib=detect`）、YOLO detection 训练集。

顶栏常驻说明条写清本库是「本机 YOLO 权重按自带类别出框」，并给出「要标权重不认识的东西去提示词标注」的入口——两页长得太像，不讲清楚一定会走错门。

## 质量标记

和提示词库共用一套标记口径，只有「来源」相关的两条按本机权重改了名，另外多一条 `masked`：

| 标记 | 含义 |
| --- | --- |
| `no_classes` | 还没有类别：先在「目标检测」页从模型类别表里勾选要标的类别 |
| `none_found` | 这张一个框都没有：可能确实没有，也可能模型没认出来 |
| `small_box` | 框太小（短边不足 12 像素），训练时容易学不动 |
| `edge_box` | 框贴画面边缘，目标可能被裁断 |
| `dup_box` | 同类别两个高度重叠的框，重复标注 |
| `unknown_class` | 标签里有登记表里不存在的类别号（类别被删过或手工改过盘） |
| `model_stale` | 标注用的权重/类别/阈值与当前设置不一致，建议重新标注（提示词库同一条叫 `prompt_stale`） |
| `model_failed` | 这次推理失败（权重缺失/显存不足/读图失败），框是旧的或缺失（提示词库同一条叫 `vlm_failed`） |
| `masked` | 这一轮出自**分割权重**：多边形轮廓只按外接水平框记录，想要轮廓得换标注方式 |
| `manual` | 人工补画或重画的框（不是模型给的），导出时置信度按 1 计 |

复核优先级由这些标记加权得出，`small_box`/`dup_box`/`model_failed` 排在前面。导出的
坐标 CSV/JSONL 与 `meta.json` 的列说明也按本库口径写（讲的是 `detect_*`，不会拿
`prompt_stale`/`vlm_failed` 教人）。

## 类别号：谁说了算

**由本库登记表决定，不是模型说了算。** COCO 里 `bus=5`，但你的登记表可能给 `bus=0`；标签文件里写的是**登记表的号**。

- **同名类别永不换号**：换权重（COCO-80 → 自训练 3 类）时同名的 `person` 继续用同一个号，先前标好的框不会一夜之间指错东西。
- **删掉的号不回收**：删了 `bus`（原 0 号）之后新建的类别拿新号，不会顶回 0 号——否则历史标签里残留的 0 号会被重新解释成别的东西。
- **只登记这个权重真的报得出的类别**：`--add-classes gas stove` 这种权重不认识的名字会被列进 `not_in_model` 并**拒绝登记**，因为收进来一个模型认不出的类别，下次「按本库全部类别标注」会整批报「认不出这些类别」，等于自己埋雷。想手工登记别的名字走「类别管理 → 新建」或 `autolabel fields --lib detect`。
- **允许词间空格**：COCO 的 `potted plant`、`fire hydrant`、`dining table` 是模型原样回报的写法，本库照收（提示词库仍然不允许，那里的类名是多模态大模型必须原样回报的 JSON 值）。导出 `data.yaml` 时会自动加引号。
- **上限 200 个类别**，一次批量最多勾 200 个。

## 模型管理：搜到 → 看懂 → 下载 → 用

`/models`（快捷键 `M`）现在按**任务**组织：`全部 / 姿态估计 / 目标检测 / 实例分割 / 旋转框检测 / 图像分类`。

- **搜索框**输入即搜（400ms 合并请求），本机模型目录按名字、任务、说明匹配，直接给中文介绍：体积 / 参数量 / 精度 mAP / 速度档位 / 适合场景 / **能标哪些类别**（COCO-80、COCO-17、ImageNet-1000）。
- **「联网搜 GitHub」** 默认关；开了才会去 GitHub 检索仓库级结果，慢。网络不通**不报错**，只在搜索框下面写「联网检索不可用：{原因}」，本机目录照常显示。GitHub 结果只有「打开 GitHub」和「复制仓库名」——那是仓库不是权重，没有可直接下载的地址，别指望一键下载。
- **下载**沿用原来的权重下载链路（带进度条、断掉的 `.part` 能看见能删）。
- **「设为检测默认」** 写的是**这个数据集的目标检测库下次用哪个权重**（存 `.autolabel/detect/prefs.json`）；姿态那套「设为默认」写的是**这台机器**的姿态默认权重（存 `configs/models.json`）。两处不是一回事，界面上文案分开写。

命令行：

```bash
python3 -m autolabel models --search yolo11 --task detect        # 搜本机模型目录，带中文介绍
python3 -m autolabel models --search yolo --task detect --remote  # 顺带联网搜 GitHub
python3 -m autolabel models --browse                              # 完整可下载目录
```

## 命令行

```bash
D=datasets/goods
python3 -m autolabel init    $D --name 货物
python3 -m autolabel import  $D ~/Pictures/货架 --lib detect        # 素材直接进目标检测库
python3 -m autolabel detect  $D --list-models                       # 本机哪些权重能用在本库
python3 -m autolabel detect  $D --model-classes yolo11n.pt          # 这个权重认得出哪些类别
python3 -m autolabel detect  $D --model yolo11n.pt --add-classes bus,person
python3 -m autolabel detect  $D --model yolo11n.pt --add-classes all --no-label   # 全部 80 类只登记不标注
python3 -m autolabel detect  $D --classes bus,person --coords --batch-name 上午批次
python3 -m autolabel detect  $D --status                            # 已标 / 待复核 / 按类别统计
python3 -m autolabel detect  $D --export --out exports/goods        # YOLO detection 训练集
```

`--add-classes bus,person` 之后直接就跑标注了；只想登记类别不想跑推理加 `--no-label`。没选权重时的顺序：**显式 `--model` → 本库上次用的（prefs）→ `yolo11n.pt`**。

一条命令跑完（导入 → 标注 → 坐标）：

```bash
python3 -m autolabel auto $D ~/Pictures/货架 --lib detect --model yolo11n.pt
```

### 参数

| 参数 | 作用 |
| --- | --- |
| `--model 权重` | 权重文件名或路径，默认上次用的那个，它决定能标哪些类别 |
| `--list-models` | 列本机权重，标出哪些能用在本库（姿态权重说明为什么用不了） |
| `--model-classes 权重` | 列这个权重自带的类别表（中文名 + 类别号），只看不动数据 |
| `--add-classes 类名` | 把权重自带的类别导入本库登记表，逗号分隔可重复，`all` 全部导入 |
| `--no-label` | 配合 `--add-classes`：只登记类别，不跑标注 |
| `--classes 类名` | 只标这些类别，默认用本库登记表里全部 |
| `--images 相对路径` | 只标这些图，默认整个目标检测库 |
| `--device` | `auto\|cuda\|mps\|cpu`，`0`/`1` 指定第几块 N 卡；默认用系统设置那档 |
| `--conf` | 置信度阈值，默认用系统设置里的值 |
| `--limit` | 只标前 N 张，试跑用 |
| `--overwrite` | 已标过的也重标（默认跳过同参数已标、人工接受、人工画过框的） |
| `--coords` / `--export` / `--out` | 顺带导出坐标文件 / YOLO 训练集 / 指定导出目录 |
| `--batch-name` | 批次名称，用于「批次管理」分组 |
| `--status` / `--quiet` | 只看汇总 / 不逐张打印 |

## 产物

```
datasets/<名称>/
├── detect_labels/<同名>.txt            YOLO detection 5 列，可直接喂训练
├── coords/<时间戳>-detect/             objects.csv、objects.jsonl、meta.json、summary.json
├── exports/<时间戳>-yolo-detect/       images/ labels/ data.yaml yolo_meta.json
└── .autolabel/detect/
    ├── index.json                      本库索引（detect_* 状态）
    ├── batches.json                    本库批次登记
    ├── classes.json                    类别登记表：类名 → 永不复用的类别号
    ├── prefs.json                      上次用的权重 / 类别 / 阈值
    ├── originals/                      首次人工修改前的原件备份
    └── history/                        撤销用的历史快照
```

索引字段一律带 `detect_` 前缀（`detect_objects` / `detect_status` / `detect_flags` / `detect_signature` / `detect_score` / `detect_classes` / `detect_model` / `detect_manual`），和姿态库、提示词库的字段互不覆盖。

## 接口

同一件事只有一个入口：检测框的读写仍走 `/api/prompt/*`，靠 `lib` 参数分流（缺省 `objects`）；只有真正新增的能力才开新接口。

| 接口 | 说明 |
| --- | --- |
| `GET /api/detect/models` | 本库能用的权重、不能用的连同原因、上次选择（prefs） |
| `GET /api/detect/model/classes?model=` | 这个权重自带哪些类别（含中文名） |
| `POST /api/detect/classes/add` | 把权重自带的类别导入本库登记表 |
| `POST /api/detect/prefs` | 设为本库默认权重（只认可用在检测的权重） |
| `POST /api/detect/run` / `/api/detect/upload` | 批量标注 / 上传并标注 |
| `GET /api/detect/summary` | 本库总览 |
| `GET /api/modelhub/search?q=&task=&remote=1` | 模型管理页的搜索（本机目录 + 可选联网） |
| `GET/POST /api/fields`、`/api/prompt/item`、`/api/prompt/status`、`/api/prompt/undo`、`/api/prompt/export`、`/api/prompt/coords` | 与提示词库共用，带 `lib=detect` 即作用于本库 |

## 常见问题

**下拉框里没有我刚放的权重**——权重目录由 `AUTOLABEL_WEIGHTS_DIR` 或默认 `models/` 决定；`--list-models` 会列出目录里的全部并说明哪些为什么不能用。改名成 `-seg` / `-obb` 结尾会被识别成分割 / 旋转框权重。

**跑起来报「这是「人体姿态」权重」**——`yolo11n-pose.pt` 之类的姿态权重出的是关键点不是框，回 `/pose` 用它。

**换了权重之后类别对不上**——不是 bug：`person` 在两个权重里都存在就继续能标，只有新权重不认识的类别会落空，任务完成消息会写明「该权重认不出 xxx」。去类别管理里按新权重重新勾一遍即可。

**跑完显示「标注 0 张」**——这些图同参数已经标过、或者被人工接受 / 手工画过框保护起来了。要重标勾「覆盖已有框」或加 `--overwrite`。

**首次打开检测页有点慢**——开页会在后台取一次上次权重的自带类别表（首次加载权重 1–3 秒），这样点开「类别管理」时列表不是空的。

**导出里没有某个类别**——那个类别在当前数据里一个框都没有，`data.yaml` 只写实际用到的类别。

**分割权重跑完只有方框、没有轮廓线**——不是坏了。本库标签是 YOLO detection 的 5 列
（`class cx cy w h`），存不下多边形，所以 `-seg` 权重出的每个轮廓只按**外接水平框**落盘，
并在图片上打一条 `masked` 标记提醒你这件事（复核页的标记说明里也写着）。要真正标轮廓，
得换支持多边形的标注工具；本项目的导出同样是 detection 格式，不是 segment 格式。

**旋转框（`-obb`）也一样**——斜的目标按外接水平框记录，旋转角不落盘。
