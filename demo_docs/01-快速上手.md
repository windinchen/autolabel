# 快速上手

## 环境

已验证：macOS（Apple M3 Ultra）+ Python 3.9.6 + `torch 2.8.0` + `ultralytics 8.4.24`，推理走 Apple Silicon MPS，无需 CUDA。抽帧依赖 `ffmpeg`。

Windows 同样双击就能起（`运行工作台.bat` / `后台服务.bat`），推理要提速到 N 卡在系统设置里切 CUDA 即可。Windows 侧要准备的只有 Python 环境：装一次 `uv`（`winget install astral-sh.uv`）依赖就自动备齐，没装就退回系统 Python 并提示你自己 `pip install -r requirements.txt`。完整说明见 `../README.md`「环境」。

```bash
python3 -m pip install -r requirements.txt   # 已装 torch/ultralytics 可跳过
python3 -m pytest tests -q                   # 1351 项测试，约 2 分钟
/opt/homebrew/bin/ruff check autolabel tests # 代码检查
```

## 一条命令跑完（推荐）

```bash
python3 -m autolabel auto datasets/myset 录像.mp4 ~/Pictures/人像 --fps 0.5
```

`auto` 会依次完成：

1. 数据集不存在则自动 `init`
2. 按扩展名分流：`.mp4/.mov/.mkv` 等 → ffmpeg 抽帧入库；其余 → 图片/目录导入（规范化 RGB、展开 EXIF 旋转、限最长边、去重）
3. 批量标注（默认 `yolo11n-pose`，可 `--extra-models` 加校验模型做共识/分歧标记）
4. QC 报告 `datasets/myset/qc/report.md`
5. 坐标文件 `datasets/myset/coords/<时间戳>/`

实测（真实手机视频 29 MB，`--fps 0.5 --max-frames 60`，双模型 MPS）：抽出 11 帧 → 去重保留 2 帧 → 14 个人、238 个关键点，端到端约 3 秒。

## 分步执行

```bash
D=datasets/demo
python3 -m autolabel init    $D --name LEAGANS.Embodied-Ai
python3 -m autolabel import  $D models/bus.jpg models/zidane.jpg
python3 -m autolabel label   $D --model yolo11n-pose.pt --render-qc 4
python3 -m autolabel qc      $D --render 10
python3 -m autolabel ca      # 只做一次：签本地 HTTPS 证书，摄像头要用
python3 -m autolabel review  $D          # 自动打开 https://localhost:8765
python3 -m autolabel coords  $D          # 只要坐标文件
python3 -m autolabel export  $D --val-ratio 0.2 --coco --coords
```

## 第二条链路：提示词标注（物品检测框）

骨骼之外想标任意物品（瓶子、背包、灭火器……），不用训模型，写一句描述让多模态大模型逐张找：

```bash
D=datasets/demo
python3 -m autolabel fields  $D --add "bottle=桌上或手里拿着的塑料水瓶，含纸杯、保温杯"
python3 -m autolabel import  $D ~/Pictures/瓶子 --lib objects       # 素材进提示词库（已在素材池的直接复用）
python3 -m autolabel prompt  $D --vlm 本地\ Ollama --limit 20      # 先试跑
python3 -m autolabel review  $D                                     # /objects 页删错框、补画漏框
python3 -m autolabel prompt  $D --coords --export                   # 出检测框坐标与训练集
yolo detect train data=$D/exports/<标签>-detect/data.yaml model=yolo11s.pt epochs=100 imgsz=640
```

写清楚「什么算这个目标、什么不算」比换更大的模型更有用。完整说明见 `09-提示词标注.md`。

两个模块是**独立的库**：`--lib pose`（默认）进姿态库、`--lib objects` 进提示词库，各自的索引、批次、标签目录、撤销快照都分开，删图不会带走对方的标注；只有 `images/` 素材池共用一份，同一帧不必传两遍（`autolabel pool $D --lib objects --add images/a.jpg` 直接认领，界面上传弹层里有「从素材池添加」）。老数据集不用先手动迁移：`review` 启动时会自动做完（幂等；只做过骨骼标注的老目录也会补齐缺失的提示词库索引，否则网页起不来）。想先看清楚会动什么，就自己跑一次 `python3 -m autolabel migrate $D`。

## 开始训练

```bash
yolo pose train data=$D/exports/<时间戳>/data.yaml model=yolo11s-pose.pt epochs=100 imgsz=640
```

已跑通的端到端结果：`LEAGANS.Embodied-Ai` 导出后训练 1 epoch，`metrics/mAP50(P) = 0.856`。

## 吞吐参考（M3 Ultra / MPS / 1920x1280 输入）

| 配置 | 速度 |
| --- | --- |
| `yolo11n-pose` imgsz=640 | 17 ms/张（约 60 张/秒） |
| `yolo11n-pose` imgsz=960 | 17 ms/张（约 58 张/秒） |
| 开 `--flip`（默认开） | 34 ms/张（约 30 张/秒，约 10 万张/小时） |
