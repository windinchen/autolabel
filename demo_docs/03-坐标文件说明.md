# 坐标文件说明

生成方式：

```bash
python3 -m autolabel coords datasets/demo                 # 写入 datasets/demo/coords/<时间戳>/
python3 -m autolabel export datasets/demo --coords        # 写进导出目录的 coords/，多一列 split
# 或在复核界面右上角点「坐标 CSV」「坐标 JSONL」直接下载
```

## 产物

| 文件 | 粒度 | 用途 |
| --- | --- | --- |
| `coords.csv` | 一行一个人 | 22 个固定列 + 每关键点 3 列（共 73 列），Excel / pandas 直接读 |
| `coords_long.csv` | 一行一个关键点 | 透视表、按关键点统计 |
| `coords.jsonl` | 一行一张图 | 程序读取，嵌套 bbox 与 17 关键点 |
| `meta.json` | 一份 | 关键点名称、骨架连线、字段含义、本次筛选条件 |
| `summary.json` | 一份 | 图片数 / 人数 / 关键点数 / 状态分布 |

## 宽表字段

固定列：

| 字段 | 含义 |
| --- | --- |
| `image` | `images/` 下的相对路径 |
| `split` | 训练/验证划分（`train` / `val`），仅 `export --coords` 有值。同一张图的归属只取决于它自己，导入新图重导不会把它换到另一侧。带子目录的素材按**导出名**对齐（`a/frame_0001.jpg` → `a__frame_0001.jpg`，与 `images/train/` 里的文件同名），JSONL 的 `stem` 字段给的就是这个名字 |
| `status` | `unreviewed` / `edited` / `approved` / `rejected` |
| `person_index` | 同图内人序号，从 0 开始 |
| `class_name` | 类别名，默认 `person` |
| `image_width` / `image_height` | 图片像素尺寸 |
| `bbox_x1 bbox_y1 bbox_x2 bbox_y2` | 边界框，**像素** xyxy |
| `bbox_cx bbox_cy bbox_w bbox_h` | 边界框，**归一化** cxcywh（与 YOLO 标签一致） |
| `person_flags` / `image_flags` | QC 标记，多值用 `|` 分隔 |
| `image_score` | 该图自动标注的平均置信度 |
| `time_sec` / `frame_index` / `video` | 视频抽帧的来源视频与时间点，非视频图为空 |
| `source` | 导入前的原始文件路径 |

关键点列：`kpNN_<名称>_x`、`kpNN_<名称>_y`、`kpNN_<名称>_v`，NN 从 01 开始。

COCO-17 顺序：`nose, left_eye, right_eye, left_ear, right_ear, left_shoulder, right_shoulder, left_elbow, right_elbow, left_wrist, right_wrist, left_hip, right_hip, left_knee, right_knee, left_ankle, right_ankle`（即 `kp01_nose` … `kp17_right_ankle`）。

## 可见性语义（重要）

| v | 含义 | 是否参与 YOLO 训练监督 |
| --- | --- | --- |
| 0 | 未标注 / 不监督 | **否** |
| 1 | 遮挡但位置可判断 | **是** |
| 2 | 清晰可见 | 是 |

ultralytics 侧是 `kpt_mask = v != 0`，所以想让某个点"不参与训练"必须设成 0，设 1 是会被监督的。

## JSONL 结构

```json
{"image": "bus.jpg", "stem": "bus", "split": "", "status": "unreviewed",
 "width": 810, "height": 1080, "image_score": 0.8184, "image_flags": [],
 "time_sec": null, "frame_index": null, "video": null, "source": "/原路径/bus.jpg",
 "objects": [{
   "index": 0, "cls": 0, "class_name": "person",
   "bbox_xyxy": [38.75, 363.99, 250.58, 933.34],
   "bbox_cxcywh_norm": [0.178598, 0.600618, 0.261514, 0.527173],
   "flags": ["limb_length_mismatch"],
   "keypoints": [{"i": 0, "name": "nose", "x": 138.92, "y": 442.39, "v": 2,
                  "x_norm": 0.171507, "y_norm": 0.409618}]
 }]}
```

像素值 = 归一化值 × 图宽/高，导出时按此校验，两者始终一致。

## pandas 读取

```python
import pandas as pd

df = pd.read_csv("datasets/demo/coords/<时间戳>/coords.csv")
boxes = df[["image", "person_index", "bbox_x1", "bbox_y1", "bbox_x2", "bbox_y2"]]
risky = df[df["person_flags"].str.len() > 0]                 # 只看被 QC 标记的人
visible = df.filter(regex=r"^kp\d{2}_.*_v$").ne(0).sum(1)   # 每个人被监督的点数
video_frames = df[df["video"] != ""]                         # 只看视频帧
```

## 筛选规则

- 默认排除 `rejected`（人工驳回的图）。
- `--include-all` 连驳回的一起导出；`--only-approved` 只导出 `approved`/`edited`。
- `--include-unlabeled` 让缺标签的图也占一行（`objects` 为空），方便对账"哪些图还没标"。
- 被排除的图片会记录在 `meta.json` 的 `skipped` 与 `summary.json` 的 `skipped_items` 里。

## 检测框坐标（提示词标注）

提示词标注产出的是**另一套文件**，列不同、含义不同，别和骨骼坐标混用：

| 文件 | 内容 |
| --- | --- |
| `coords/<标签>/objects.csv` | 宽表，一个检测框一行：`image` `status` `box_index` `class_id` `class_name` `display_name` `image_width` `image_height` `bbox_x1/y1/x2/y2`（像素）`bbox_cx/cy/w/h`（归一化）`poly_points` `box_flags` `image_flags` `image_score` `time_sec` `video` `source` |
| `coords/<标签>/objects_long.csv` | 长表，一个坐标分量一行，便于透视 |
| `coords/<标签>/objects.jsonl` | 一个检测框一条 JSON，字段同上 |

- `class_name` 是字段的英文类名（与 `data.yaml` 的 `names` 一致），`display_name` 是中文显示名。
- `box_flags` / `image_flags` 是逐框与整图的质量标记（`small_box` / `edge_box` / `dup_box` / `manual` 等），含义见 `09-提示词标注.md`。
- `manual` 表示这个框是人工补画或重画的，导出时置信度按 1 计。
- `poly_points` 是这一框的轮廓点数，`0` = 只有方框没有轮廓（出自普通检测权重，或轮廓
  与方框对不上被丢弃）。非 0 的框导出训练集时会写成 YOLO 标准分割行，能直接分割训练。
- 命令行 `autolabel prompt --coords` 生成，界面在「提示词标注」页与工作台下载。

## 导出 YOLO 标准训练集

坐标文件是给人和脚本读的，真正喂给 `yolo` 训练的是另一套目录产物，两条链路各出一份：

| 产物 | 姿态标注 | 提示词标注 |
| --- | --- | --- |
| 目录 | `exports/<时间戳>/` | `exports/<标签>-detect/` |
| 结构 | `images/{train,val}` + `labels/{train,val}` + `data.yaml` + `manifest.json` | 同结构，另附 `prompt_meta.json` |
| 标签每行 | `class cx cy w h` + 17×`(x y v)` | `class_id cx cy w h`，类别号重映射成连续 `0..N-1` |
| 界面按钮 | 姿态页右上角 `YOLO 训练集`、工作台「人体骨骼」行 `导出 YOLO 训练集` | 提示词页右上角 `YOLO 训练集`、批量弹层 `导出数据集`、工作台「检测框」行 `导出 YOLO 训练集` |
| 接口 | `POST /api/export` | `POST /api/prompt/export` |
| 定位目录 | `POST /api/export/reveal` | `POST /api/export/reveal`（同一个接口，只认 `exports/` 下的路径） |
| 重复导出 | 内容没变直接复用最近一份 | 同左 |
| 命令行 | `autolabel export <数据集>` | `autolabel prompt <数据集> --export` |

- 取哪些图：`scope=reviewed`（默认，剔掉驳回的）/ `approved`（只要人工接受过的）/ `all`（全都要）。界面走默认值，命令行用 `--only-approved` / `--include-all`。
- 默认 `val_ratio=0.2` 切 train/val，且**至少留 1 张验证图**，否则 `yolo pose train` 的 val 阶段是空的、拿不到 pose 指标。
- **验证集成员是稳定的**：按 `(seed, 图片相对路径)` 的 SHA-256 分桶决定归属，一张图进不进 val 只跟它自己有关。以前是整表 shuffle 取前 N 张，名次取决于「当次一共多少张」——补 9 张图重导，原来的验证图会掉进 train，同一帧既训练又算指标，两次导出的指标不可比。比例仍按 `val_ratio` 收敛（哈希分桶是等概率的），只是不再随数据集规模漂移；换 `seed` 会换一批人，换完依旧可复现。
- 背景图（无人 / 无框）按 `max_empty_ratio`（默认 0.15）掺入当负样本，避免负样本淹没正样本。
- **输出文件名带子目录前缀**：导出目录是平的，`images/a/frame_0001.jpg` 与 `images/b/frame_0001.jpg` 以前会写成同一个 `frame_0001.jpg`——后写的把前面的连图片带标签一起盖掉，`manifest.json` 与 COCO 里却仍记 4 张，只有样本数对不上时才被发现。现在把子目录压进名字（`a__frame_0001.jpg`），两条链路（骨骼 / 检测框）同一套规则；素材平铺时输出名与以前完全一致。
- **软链是相对路径**：`--mode symlink`（默认）写 `../../../images/...`，数据集整体改名或搬家后链接仍然连得上；以前是绝对路径，换个挂载点整批链接就断，只能重导一次。
- **`flip_idx` 按关键点数收敛**：17 点用 COCO 标准左右配对，点数更少时配对落到范围外的点改成自己映自己，点数更多时补齐，始终是当前点数的一个合法排列。
- **COCO 关键点补齐**：标签点数少于声明的 `kpt_shape`（人工删过点、老版本写的标签）时，`coco_keypoints.json` 的 `keypoints` 补零到 `点数×3`，否则从缺失点往后每一组 `(x, y, v)` 整体错位，坐标全是错的但文件看起来完全正常。
- 产物是目录不是单文件，浏览器下载不了，所以按钮点下去由后端现场生成。**路径不会只闪一次**：模块页顶栏下面与门户导出行都常驻一行「上次导出」，带完整路径与三个按钮——**在访达中显示**（macOS；Windows 显示「在资源管理器中显示」）、**复制路径**、**复制训练命令**（数据来自 `/api/dataset` 的 `exports_recent`，扫 `exports/` 目录取最近 8 份，按时间倒序）。导出成功的瞬间后端还会自动帮你打开一次目录，不用再自己找。开训命令就是：

```bash
yolo pose train data=<数据集>/exports/<时间戳>/data.yaml model=yolo11s-pose.pt epochs=100 imgsz=640
```

- 姿态产物还能带 `coco=true`（附 `coco_keypoints.json`，一行一张图的 COCO 关键点）与 `coords=true`（把坐标文件一并写进导出目录并多一列 `split`），界面默认都不开，命令行用 `--coco` / `--coords`。
- 库里没有可导出的帧时接口直接报错，不落空目录，而且**提示只指真能改的那个开关**：库里连图都没有 → 「姿态库还没有图片：先导入图片或抽帧」；整库一张骨骼标签都没有 → 「姿态库还没有任何骨骼标签：先跑一次自动标注（命令行 `autolabel auto` / `annotate`，或在复核界面手动画一副骨骼再保存）」；有标签、只是被导出范围滤空 → 「这个导出范围里没有带骨骼标签的帧（库里共 N 张带标签）：换个导出范围，或先把带标签的帧点成「接受」」。
- 选中的帧标签**全部**读不通时也算失败：报「选中的 N 帧标签全都读不通，一张都没导出」并带上 `文件:行号`，不会给你一份 0 张的"训练集"（个别帧读不通只跳过那一张，其余照常导出）。
- **重复点导出不再堆目录**：界面导出会把「这次收哪些图 + 用什么参数」压成内容指纹（读标签原文，连把 `0.500` 改成 `0.501` 这种长度没变的改动都能识别），与 `exports/` 里最近一份比对；一致就复用那份目录并提示「标签没有变化，已复用上次导出」，改过一个关键点或换了 `scope` 都会重新生成。命令行显式给了 `--out` / `--tag` 时永远按你指定的名字新建。
- 同一秒里连点两次导出、参数又不同（比如一次 `reviewed` 一次 `all`）时，第二份自动叫 `<时间戳>-2`，两批文件不会混进同一个目录。
